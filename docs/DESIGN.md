# Parry Pierce — 아이디어 정리

> 거대한 적의 몸 위를 날아다니며 적의 공격을 패리하고, 그 반동으로 갑옷을 부순 뒤 심장을 한 번에 관통하는 게임.
> 장르: **Parry Action + Pinball + Guided Projectile**
> 핵심: 적의 공격을 피하는 게 아니라, **적의 공격을 이용해 자기 몸을 조종**하는 게임.

---

## 0. 이번 프로토타입에서 정한 방향 (v0.1)

| 항목 | 결정 |
|---|---|
| 시점/배경 | 할로우 나이트: 실크송 같은 **2D 사이드뷰**. 어두운 원경 + 안개 + 빛줄기 + 먼지, 전경은 더 어둡게 |
| 스케일 | 거대한 적(약 2,800px) vs 작은 주인공(반지름 9px의 '살아있는 창') |
| 적 방향 | 옆모습, 오른쪽을 바라봄 → 가슴 **앞면**에 갑옷 격자가 드러나 있음 (2D에서 '구멍 뚫기'가 성립하도록) |
| 실패 | 바닥에 떨어지면 카메라에 **적의 발만 보임**. 다시 시도하려면 **상체(심장)까지 다시 올라가야** 함 (부순 갑옷은 유지) |
| 패리 반동 | **초안 A: 패리 성공 시 자동으로 위로 솟구침** (좌우는 공격 방향에 따라 약간) |
| 직격 | **적에게 돌진해서 직격하면 다시 위로 튀어오름** (갑옷이면 내구도 감소) |
| 승리 | 심장에 직격(돌진 또는 고속 충돌) → 즉시 승리 |

### 높이 = 진행도
바닥(발) → 무릎 → 허리 → **심장(가슴, 약 1,880px)** → 머리.
스스로는 상승할 수 없다(위쪽 입력은 '활공' = 낙하 속도만 줄임). 높이는 **패리**와 **직격 반동**으로만 번다.

## 1. 기본 게임 루프

```text
공중에서 위치 조정(약한 무한 추진 / 활공)
  → 돌진으로 원하는 위치에 접근 (게이지 소비)
  → 적이 공격 → 패리
  → 위로 솟구침 + 게이지 회복
  → 갑옷에 직격 → 갑옷 파괴 + 다시 위로 튐
  → 반복 → 갑옷에 구멍 → 구멍을 정확히 통과 → 심장 관통 → 승리
```
보스 HP를 깎는 게임이 아니라 **퍼즐처럼 방어 구조를 뚫는 게임**.

## 2. 이동
- **일반 추진(무한)**: 약함. 마우스 방향으로 좌우/하강. 마우스를 위로 두면 활공(낙하 상한 900 → 230).
- **돌진(게이지 1칸)**: 마우스 방향으로 빠르게. 갑옷을 노리거나 공격을 유도할 때.
- **추진 게이지**: 5칸. 돌진 −1, GOOD 패리 +1, PERFECT 패리 +2. 바닥에 있으면 1초당 +1(소프트락 방지).

## 3. 패리
- 우클릭 / Space. 판정 범위는 몸보다 넓다(+30px).
- 입력 후 0.22초 창. 처음 0.09초 안에 막으면 **PERFECT**(늦게 = 충돌 직전에 누를수록 PERFECT).
- 성공: 피해 없음, 위로 솟구침(PERFECT 1350 / GOOD 1000), 게이지 회복, 히트스톱·흔들림·플래시·충격파·효과음.
- PERFECT 직후 1초간 '강화' → 갑옷 피해 2배.
- 실패(헛패리): 0.35초 재입력 불가. 공격을 맞으면 HP −1 (3개), 넉백·경직.

## 4. 갑옷 / 심장
- 가슴 앞면 4열 × 7행 격자. 가장 안쪽 열 가운데가 심장.
- 열별 내구도(안→밖): 1 / 2 / 2 / 3. 바깥쪽이 단단함.
- 몸/갑옷은 핀볼판처럼 튕긴다. 그냥 닿으면 약하게 튕김(몸 위에 서 있을 수 없음), **직격**이면 위로 크게 튕김.

## 5. 적 공격 (높이에 따라 선택, 공격 사이 1.2~2.2초 휴식)
| 공격 | 사용 높이 | 예고 | 패리하면 |
|---|---|---|---|
| 내려찍기(발) | 바닥 근처 | 발이 플레이어 위로 들림 + 바닥 그림자/붉은 선 | 발이 튕겨 올라가고 플레이어는 위로 |
| 충격파 | 내려찍기 착지 순간 지면 | — | 바닥에서 바로 이륙 |
| 휘두르기(주먹) | 중·상단 | 화면을 가로지르는 붉은 선 + 반짝임 | 주먹이 튕겨나감 |
| 눈 탄환 ×3 | 전 높이 | 눈이 밝아짐 | 탄 소멸 |

## 6. 아직 열어둔 가지 (프로토타입하면서 실험)

### ① 패리 반동 방향
- **A. 자동으로 위 (현재 구현)**
- B. 패리 순간 마우스 방향으로 약간 조절
- C. 패리 직전 입력 방향으로 결정

### ② 실패 처리
- 현재: 바닥 = 소프트 실패(다시 올라가기) + HP 3 (0이면 전체 리셋)
- 대안: 바닥 즉시 실패 / BOOST ×3 같은 제한된 재발진(응급복구 수단, 패리 대체가 되면 안 됨)

### ③ 직격 반동
- 현재 모든 몸 부위에서 직격 반동이 있음 → **다리를 돌진으로 연속 직격해서 오르는** 플레이가 가능한지, 패리를 대체해버리는지 확인 필요.
- 대안: 직격 반동은 갑옷에서만 / 직격으로는 게이지를 못 얻게 / 반동 높이 축소

### ④ 갑옷 종류 (확장)
일반 / 반사(강하게 튕김) / 흡수(속도 죽임) / 가시(피해) / 이동 / 약점

### ⑤ 공격 종류 (확장)
주먹, 검, 레이저, 충격파, 탄환, 휘두르기, 내려찍기 — 공격마다 패리 타이밍과 반동 방향이 달라야 함

### ⑥ 보스 = 스테이지
거대한 기사(갑옷→심장), 골렘(결정→코어), 용(움직이는 비늘 사이), 기계(장갑판→핵), 생물(몸 안으로 들어가는 입구)

## 7. 이 프로토타입으로 확인할 것
1. **패리가 재미있는가?** — 적 공격 → 패리 → 쾅!
2. **패리 후 날아가는 게 재미있는가?** — "이 반동으로 원하는 곳에 갈 수 있구나"
3. **다시 갑옷을 노리는 게 재미있는가?** — 패리 → 날아감 → 갑옷 → 방향 조절 → 다음 패리
4. (이번 추가) **추락 후 다시 올라가는 과정**이 벌이 아니라 재미있는 재도전인가?

목표: `패리 → 날아감 → 갑옷에 부딪힘 → 다시 패리` 루프가 **10분 동안 재미있는지**.

플레이어가 이런 생각을 하게 되면 성공:
> "저 공격을 저 타이밍에 패리하면 저쪽 갑옷으로 날아가겠는데?"
> "구멍이 저쪽에 생겼으니까 이번 패리로 튕겨나간 다음 돌진해서 들어가자."

## 0-b. v0.2 변경 (보스 = 배경)

| 항목 | 내용 |
|---|---|
| 보스 문법 | 보스는 **배경에 정면으로 서 있고 몸은 충돌/피해가 없다.** 판정은 ① 적의 공격 순간 ② 내 돌진(공격) 순간에만 생긴다 → 가로 이동이 막히지 않음 |
| 타격점 | 돌진 중에만 가슴 갑옷 5x5 격자와 심장이 판정을 가진다(돌진 중 갑옷 테두리가 금빛으로 드러남). 바깥 칸 내구 3 / 안쪽 칸 2 / 중앙 심장. 구멍을 뚫어 돌진으로 통과하면 승리 |
| 적 공격 | **내려찍기**(발 들기 경고 → 착지 + 양방향 바닥 충격파), **주먹 내려치기**(조준 원 경고 → 락온 → 직격), **탄 부채꼴**(눈에서 5발 x 3연), **탄 흩뿌리기**(18발 방사) |
| 패리 | 성공 시 **추진 게이지 가득**. 솟구침 PERFECT 1850 / GOOD 1450 (이전 1350/1000) |
| 돌진 | 속도 1750 x 0.22초 (이전 1050 x 0.2). **타격 성공 시 게이지 1칸 환급**, 반대쪽으로 1500 속도로 튀어오름(이전 700) |
| 열린 질문 | 돌진 타격이 게이지를 환급하므로, 갑옷이 남아있는 동안은 패리 없이도 '돌진 → 튕김 → 돌진'으로 계속 높이를 유지할 수 있음. 패리의 가치가 충분한지(패리 = 가득 충전 + 안전한 상승) 플레이 확인 필요 |
