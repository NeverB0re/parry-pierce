# 도트(픽셀) 그래픽 에셋 찾고 입히기 — 완전 초보자용

> 이 게임은 지금 그림 파일이 하나도 없고 전부 코드로 그립니다. 도트 에셋을 입히려면 "그림 파일(PNG)을 구하고 → 게임에 넣고 → 코드가 그 그림을 쓰게" 하는 3단계가 필요합니다.
> 1단계(구하기)는 직접 하시고, 2·3단계(넣기·연결)는 PNG 파일만 주시면 제가 해 드릴 수 있습니다.

---

## 0. 먼저 알아둘 말 (3개면 충분)

| 말 | 뜻 |
|---|---|
| **스프라이트** | 캐릭터·물건 하나를 그린 작은 그림 (PNG 파일) |
| **스프라이트시트** | 여러 장의 그림(움직임 프레임)을 한 파일에 격자로 모아 둔 것 |
| **타일셋** | 바닥·벽처럼 반복해서 쓰는 네모난 조각들 모음 |

도트 그림은 "점 하나하나가 보이는" 작은 그림입니다. 예: 32×32 픽셀 짜리 그림을 화면에서 4배 키우면 128×128로 보이고, 점이 네모로 또렷하게 보입니다.

## 1. 어디서 구하나 (무료)

| 사이트 | 특징 | 주소 |
|---|---|---|
| **itch.io** | 가장 많음. 무료 에셋은 "Game Assets → Free" 필터로 찾기 | itch.io/game-assets/free/tag-pixel-art |
| **Kenney** | 전부 CC0(완전 자유)이라 가장 안전. 도트 외에 단순한 그림도 많음 | kenney.nl/assets |
| **OpenGameArt** | 오래된 무료 에셋 저장소. 라이선스가 제각각이라 확인 필수 | opengameart.org |

검색어 예시: `pixel art robot boss`, `pixel art rocket`, `pixel art lava`, `pixel art dark ruins tileset`, `pixel art explosion`.

### 이 게임에 필요한 그림 목록
| 필요한 것 | 크기 감 | 비고 |
|---|---|---|
| 작은 로켓(주인공) | 16~32px | 위/옆 방향이 있으면 좋음. 돌려서 쓰므로 한 장이어도 됨 |
| 거대한 적 (몸·팔·머리) | 매우 큼 | **가장 구하기 어려움** — 한 장짜리 거대 보스 그림 또는 부품별 그림이 필요 |
| 하트 모양 강철 코어와 껍질 판 | 중간 | 직접 그리는 편이 빠를 수 있음 |
| 용암 | 타일(반복) | 흔함 |
| 폐허·성 배경 | 타일 또는 한 장 | 흔함 |
| 폭발·불꽃·파편 이펙트 | 스프라이트시트 | 흔함 |
| 탄환(금색 구슬) | 8~16px | 쉬움 |

> **현실적인 조언**: 거대 보스는 "그림 하나에 딱 맞는 무료 에셋"을 찾기 어렵습니다. 주인공·용암·배경·이펙트는 구하고, 보스는 (a) 비슷한 에셋을 크게 조립하거나 (b) 도트 편집기로 직접 그리는 쪽이 현실적입니다.

## 2. 반드시 확인: 라이선스

다운로드 페이지에서 **License** 항목을 찾아 아래 중 무엇인지 보세요.

| 표기 | 뜻 | 이 게임을 GitHub에 공개해도 되나 |
|---|---|---|
| **CC0** / Public Domain | 마음대로 써도 됨 | 예 |
| **CC-BY** | 쓰되 **만든 사람 이름을 표시**해야 함 | 예, README에 출처 표시 |
| **CC-BY-SA** | 위 + 이 게임 그림도 같은 조건으로 | 조심 (그림 부분만) |
| **CC-BY-NC** / "비상업적" | 돈 버는 용도 금지 | 공개는 대체로 괜찮지만 판매하면 안 됨 |
| 라이선스 표기 없음 / "All rights reserved" | 쓰면 안 됨 | 아니오 |

> 이 저장소는 공개이므로 그림 파일도 **그대로 공개**됩니다. 재배포가 금지된 에셋은 넣으면 안 됩니다. 확신이 없으면 저한테 라이선스 문구를 붙여 넣어 주세요.

## 4. 받은 그림을 프로젝트에 넣기

1. 에셋을 다운로드하면 보통 **ZIP 파일**입니다. 압축을 풉니다.
2. 안에서 쓸 **PNG 파일**만 고릅니다. (`readme.txt` / `license.txt`도 같이 보관하세요.)
3. 이 폴더에 새 폴더를 만들어 넣습니다:

   ```
   C:\Users\JMS\Downloads\parry\art\
       rocket.png
       lava_tiles.png
       explosion_sheet.png
       LICENSE_이름.txt   ← 출처·라이선스 파일
   ```

4. 끝입니다. 나머지(Godot에 읽히게 하고, 코드가 쓰게 하는 것)는 저에게 "art 폴더에 이런 그림 넣었어"라고 말씀해 주시면 됩니다.

> 파일 이름은 영어·숫자·밑줄로, 공백 없이 지어 주세요. 다운로드한 ZIP은 `art` 밖 아무 곳에나 두셔도 됩니다.

### 도트가 흐릿하게 보이지 않게 (제가 해 둘 설정)
Godot는 기본으로 그림을 부드럽게 늘려서 도트가 번집니다. 아래 설정을 해야 또렷한 네모로 보입니다. 이미 예전에 시험한 설정이니 에셋을 넣을 때 같이 적용합니다.

- 프로젝트 설정 → Rendering → Textures → **Default Texture Filter = Nearest**
- (직접 열어서 하실 경우) 가져온 PNG를 선택 → Import 탭 → *Filter*를 끄고 → Reimport

## 5. 이 게임에서 에셋을 쓰는 방식 (참고)

지금은 `scripts/player.gd`의 `_draw()` 함수가 선과 도형으로 로켓을 그립니다. 에셋을 쓰려면 이 부분을 "그림 파일 한 장을 그 자리에 그려라"로 바꿉니다. 코드 몇 줄 바뀌는 수준이라 어렵지 않습니다. 오히려 어려운 건 **크기 맞추기**입니다.

| 문제 | 설명 | 해결 |
|---|---|---|
| 크기 | 이 게임의 로켓은 길이 약 56px, 보스는 3,000px 가까이 됩니다. 도트 그림 하나의 점 크기가 로켓은 2px, 보스는 5~6px처럼 제각각이면 이상해 보입니다 | **점 크기를 하나로 통일**합니다. 예: 도트 1개 = 화면 3px로 정하고, 그림마다 몇 px로 그려야 하는지 계산해서 알려 드립니다 |
| 회전 | 로켓은 방향을 따라 돕니다. 도트 그림을 대각선으로 돌리면 점이 비틀어져 지저분해집니다 | 8방향 그림을 따로 구하거나, 그냥 돌려서 쓰고 (조금 번짐) 타협하거나 |
| 움직임 | 팔이 휘두르는 연출은 코드로 계산한 선입니다 | 보스는 "정지 그림 + 코드 움직임"이 현실적입니다. 부품별 그림(팔·주먹·몸통)을 코드가 돌려 붙입니다 |

그래서 순서를 이렇게 추천합니다.

1. **주인공 로켓** 한 장 (구하거나 Piskel로 직접) → 가장 쉽게 효과를 체감
2. 용암·배경 타일
3. 폭발 등 이펙트 시트
4. 코어 껍질 판 (직접 그리기 쉬움: 단순한 판 그림 3~4종)
5. 보스 (가장 마지막)
