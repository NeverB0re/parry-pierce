# 용어집 (UI 문구 기준)

설정(docs/STORY.md)에 맞춰 화면에 보이는 말을 정리한 표. 코드 내부 이름은 그대로 둔다 (`parry_dash`, `charge` 등).
조작을 설명하는 말(돌진, 좌클릭·우클릭)은 처음 하는 사람이 이해하도록 그대로 둔다.

| 코드·옛 이름 | 화면 표기 | 비고 |
|---|---|---|
| 패리 돌진 | **리버스 드라이브** | 설정의 핵심 이름. 받아낸 에너지를 추진기로 방출해 충돌 |
| 패리 | **패리** | 타이틀과 일치. 설정상 "에너지 흡수"의 입력 |
| 패리 불가 | **패리 불가** | 보라색 = 흡수할 수 없는 에너지 |
| 차지 돌진 | **차지 강습** | 사용자 지정 |
| 받아치기·저지 | **요격** | 주인공 기체가 "실험용 요격기" |
| 퍼펙트 회피 | **퍼펙트 회피** | 이름 유지 |
| 퍼펙트 회피 버프 | **동조** / 레이저를 피한 강한 버프 = **완전 동조** | |
| 코어 파괴 (승리 배너) | **코어 에너지 확보** | 부수는 것이 아니라 에너지를 추출 |
| 심장/하트 껍질 | **동력 코어 / 장갑** | |
| 부위 | **외부 시스템** (포대 = 무장, 관절 = 구동부) | HUD "외부 시스템 4" |
| 목숨 | **실드 셀** | |
| 스턴 | **제어 불능** | |
| 용암 | **융해 지대** | 콜로서스가 녹이는 행성 표면 |
| 발판 | **불시착 지점** | 시작·부활 = 불시착한 곳에서 이륙 |
| 게임 오버 배너 "부서졌다" | **기체 손실** | |
| 큰 탄 / 작은 탄 | **주탄 / 잔탄** | 주탄(둥근 금색) 패리 = 리버스 드라이브, 잔탄(검붉은 별) 패리 = 흡수 |
| 근접공격 | **근접공격 (회피 불가)** | 팔 휘두르기·프레스. 일반 돌진의 무적으로 통과 못 함 |
| 천장 압착 | **프레스** | 탄막 요새의 근접공격 |
| 퍼지는 고리 | **동심원 파동** | 탄막 요새의 패리 불가 공격 |
| 유도탄 | **유도탄** | 크고 느리게 쫓아오는 주탄 (도는 고리) |
| 바닥 폭탄 | **융해 기뢰** | 탄막 요새의 바닥 패턴 |
| 탄 되돌리기 | **반사** (반사 코어) | 반사된 탄은 청백색 |
