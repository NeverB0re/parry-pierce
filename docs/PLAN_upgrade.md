# 업그레이드 기획서 (초안) — 코어 아이템 + 부산물 노드 트리

> 상태: **초안 — 4장 질문 대기**. 구현은 보스가 둘 이상 생긴 뒤. 수치는 현재 상수 기준의 시작값.
> 전제: 스테이지식 진행(FTL 도약 한 번 = 한 스테이지), 죽으면 그 스테이지부터 다시. 설정은 [STORY.md](STORY.md), 용어는 [GLOSSARY.md](GLOSSARY.md).

---

## 1. 두 가지 성장 축 (확정된 방향)

| | **코어 아이템** | **부산물 업그레이드 (노드 트리)** |
|---|---|---|
| 출처 | 콜로서스의 **고유 코어** (보스당 1개, 고정) | 클리어 시 얻는 **부산물**(부품·보조 에너지) |
| 성격 | **플레이스타일을 바꾸는 기능** (성능이 아니라 방식) | **영구 능력 강화** (수치·판정·유틸) |
| 보유 | 모두 수집, **한 번에 하나만 장착**, 정비 때 자유롭게 **교체** | 영구. 되돌릴 수 없음 |
| 획득량 | 보스를 처음 처리할 때 1개 | **보스당 1포인트**, 한 번만 |
| 제한 | 장착 슬롯 1개 | **전부 찍을 수 없다** (포인트 < 노드 수) → 어느 트리에 투자할지 선택 |

설정 연결: 코어 = 에너지원이므로 **기능(어떻게 싸우나)**, 부산물 = 부품·보조 연료이므로 **강화(얼마나 강한가)**.

## 2. 코어 아이템

### 2-1. 규칙
- 보스 하나당 정확히 하나, 효과는 고정. 정비 화면에서 장착/해제/교체 (스테이지 시작 전).
- **장점만 있는 아이템은 만들지 않는다**: 각 코어에 가벼운 대가(트레이드오프)를 붙여, 상황에 따라 바꿔 끼울 이유를 만든다.
- 아이템 효과는 기본 조작을 바꾸지 않고 **기존 동작에 한 가지 규칙을 얹는** 형태.

### 2-2. 후보 (보스 유형 ↔ 코어, 초안)

| 코어 | 보스 유형 | 효과 | 대가 | 비고 |
|---|---|---|---|---|
| **기동 코어** | 현재 보스(올라운더) | 돌진 거리 +25%, 활공 낙하 느리게 | 차지 강습 모으는 시간 +0.1초 | 가장 평범한 "움직임" 스타일. 첫 번째로 얻어 기능을 익히게 함 |
| **반사 코어** | 패리 중심형 (탄막+유도탄) | 리버스 드라이브 중 닿은 탄을 반사(보스에 피해). 유도탄은 되돌려 보냄 | 리버스 드라이브 직접 피해 −20% | 사용자 아이디어. 반사 범위는 기체보다 넓게(반지름 ≈70px), 돌진 직후 0.3초 유지 |
| **동조 코어** | 회피 중심형 (패리 불가 다수) | 퍼펙트 회피 시 주변 탄 소거, 동조 버프가 1회가 아니라 **4초 지속** | 돌진 쿨다운 +0.1초 | 퍼펙트 회피를 많이 시키는 보스와 짝 |
| **강습 코어** | 차지 강습 중심형 (다지) | 요격 성공 시 차지 즉시 충전, 연쇄 요격마다 피해 +2(최대 +6) | 패리 판정 시간 −0.05초 | 다지 보스의 번갈아 휘두르기를 잇는 재미 |
| **연쇄 코어** | 소환형 (잡몹) | 돌진이 소형 적을 관통, 관통마다 돌진 쿨다운 −0.15초 | 보스 본체에 가하는 일반 돌진 피해 −50% | 잡몹 소탕 전용. 본체 보스전에서는 바꿔 낄 이유 생김 |

> 이 표의 효과는 시작 안일 뿐이고, 보스 설계가 정해지면 코어도 같이 다듬는다.

## 3. 부산물 업그레이드 — 3개 트리

### 3-1. 규칙
- 보스를 처음 클리어하면 **1포인트**. 재도전으로는 얻지 않는다(파밍 방지).
- 포인트는 세 트리 중 어디에든 쓸 수 있다. 트리 안에서는 **선행 노드**가 있어야 다음 노드가 열린다.
- **전부 찍을 수 없게** 노드 수를 포인트 수보다 많게 한다 (노드 총수 ≈ 포인트 총수 × 2).
- 영구·되돌릴 수 없음 (설정: 부산물로 기체를 개조한 것).
- 보스는 **포인트 0으로도 깰 수 있게** 설계한다 (업그레이드는 편의·성장이지 필수 조건이 아니다).

### 3-2. 세 트리

**판정 완화 (조작을 너그럽게)**

| 노드 | 효과 |
|---|---|
| A1 | 패리 판정 유지 0.2초 → 0.25초 |
| A2 | 리버스 드라이브 조준 유예 1.4초 → 1.8초 (PERFECT 1.9 → 2.3) |
| A3 (A1 후) | 퍼펙트 회피 판정 0.12초 → 0.16초 |
| A4 (A2 후) | 조준 보조 범위 +30% |
| A5 (A3·A4 후, 정점) | 입력 기억 시간 증가(돌진 0.2→0.3초, 패리 0.15→0.25초) + 제어 불능 0.9→0.7초 |

**스텟 증가 (더 세게·더 버티게)**

| 노드 | 효과 |
|---|---|
| P1 | 실드 셀 +1 (3 → 4) |
| P2 | 차지 강습 피해 3 → 4 |
| P3 (P2 후) | 요격 피해 8 → 11 |
| P4 (P1 후) | 리버스 드라이브 피해 12 → 14 (PERFECT 16 → 19) |
| P5 (P3·P4 후, 정점) | 동조 배율 ×2 → ×3 (완전 동조 ×4 → ×5) |

**유틸리티 (기동·편의)**

| 노드 | 효과 |
|---|---|
| U1 | 돌진 쿨다운 0.7초 → 0.6초 |
| U2 | 차지 시간 0.6초 → 0.5초 |
| U3 (U1 후) | 적중 후 솟구침 높이 +15% |
| U4 (U2 후) | 퍼펙트 회피 성공 시 실드 셀 1 회복 (스테이지당 1회) |
| U5 (U3·U4 후, 정점) | 리버스 드라이브 직후 무적 여유 0.7초 → 1.1초, 돌진 쿨다운 즉시 초기화 |

> 한 트리에 5노드, 총 15노드. 보스가 6~7마리라면 포인트 6~7개 → 노드의 약 절반을 찍는다.
> 정점 노드가 "트리를 파면 얻는 보상"이다. 두 트리의 정점을 모두 얻을 수 없도록 포인트를 설계한다.

## 4. 확인할 점 (질문)

1. **트리 선택 방식**: (A) 포인트를 받으면 노드를 자유롭게 고른다(선행 조건만 만족) / (B) 세 트리 중 하나를 고르면 그 트리의 다음 노드가 순서대로 열린다. 위 표는 A 기준입니다.
2. **보스 수 기준**: 아직 미정이니 "노드 수 = 포인트 수의 약 2배"를 기준으로 두고, 보스 수가 정해지면 노드를 더하거나 뺄까요?
3. **코어의 대가(트레이드오프)**: 넣는 방향이 맞는지? 대가 없는 순수 이득 코어를 원하신다면 교체 이유가 없어져 "가장 좋은 코어 하나만 쓰게" 될 위험이 있습니다.
4. **첫 보스의 코어**: 위 "기동 코어"로 갈지, 다른 기능으로 할지.

## 5. 구현 순서 (제안)

1. **데이터 틀**: `upgrades.gd`에 노드 정의(id, 트리, 선행, 효과 = {상수 이름: 증감}) + 코어 아이템 정의(훅 이름). 플레이어는 상수를 직접 읽지 않고 `mods` 딕셔너리를 거쳐 읽는다.
2. **저장**: `user://profile.cfg` — 클리어한 보스, 찍은 노드, 보유 코어, 장착 코어.
3. **정비 화면**: 스테이지 클리어 후/시작 전 UI. 좌측 3트리, 우측 코어 목록·장착, 하단 현재 효과 요약.
4. **코어 아이템 훅**: 리버스 드라이브 중 탄 접촉, 퍼펙트 회피, 요격, 돌진 관통 같은 이벤트에 코어 효과를 연결.
5. **스테이지 틀**: 스테이지 목록, 보스 팩토리, 클리어 → 정비 → 다음 스테이지.
6. 이후 두 번째 콜로서스(패리 중심형)와 함께 첫 코어(반사)를 넣어 실제 효과를 확인.

헤드리스 테스트: 노드 선행 조건, 포인트 소모, 영구 저장, 코어 효과 적용/해제(교체 시 효과가 남지 않는지).
