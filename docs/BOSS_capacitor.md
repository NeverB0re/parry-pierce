# 6스테이지 콜로서스 — 축전 방벽 (에너지 충전형, 가칭) 기획서

> 상태: 2026-10-23 초안. 사용자 결정은 2장, 남은 질문은 10장.
> 이 보스부터 새 탄막 구조(지형 탄 + 기회 탄, [RULES.md](RULES.md) 7장)를 쓴다. 규칙 점검은 9장.

## 1. 한 줄 요약

맵 맨 위를 **성벽처럼 가로막은 거대한 에너지 저장소**. 성벽은 잔탄으로 지은 **움직이는 미로**를 아래로 쏟아낸다.
플레이어는 아래에서부터 미로를 뚫고 올라가 길 곳곳에 놓인 **금색 주탄**을 패리해 저장소로 되꽂는다. 되꽂을 때마다 저장소가 **과열**되고, 끝까지 과열되면 **대폭발**로 끝난다.

## 2. 확정된 것 (2026-10-23 사용자 결정)

- 에너지 충전형: 주탄을 패리해 되돌려 **저장소를 과열**시키는 것이 딜이다. 몇 번 해내면 과열 끝에 대폭발로 클리어.
- 패턴이 나오는 동안은 **생존에 집중하는 구간**이다. 그동안 **적의 타격점은 닫혀** 있고 조준점도 뜨지 않는다 (동조 드라이브 난사로 무적만 이어 가며 딜하는 것을 막는다).
- **보라 탄은 만들지 않는다.** 지형(미로)은 **잔탄**으로 짓는다.
- 보라는 **줄넘기** 패턴에만 쓴다.
- **게임 규칙 변경 (모든 보스, v0.128 적용)**: 잔탄을 패리해 흡수해도 **패리 쿨다운이 평소대로 돈다.** 잔탄을 패리 연타로 버틸 수 없다 (안전망은 돌진 무적·회피로 충분).
- 무대: 맵이 원래 세로로 길다. 보스는 **맵 최상단에 성벽처럼** 있고, 플레이어는 **아래에서부터** 패턴을 뚫거나 피하며 올라간다.
- 근접공격 = **전장을 좁히는 압착** (2보스 프레스처럼). 쳐내면(요격) 다시 올라간다. 못 쳐내고 두면 전장이 좁아진 채 한동안 유지되다가, 한참 뒤에 돌아간다.

## 3. 진행: 과열 게이지

- 게이지 = 체력. 따로 외부 시스템·코어 단계를 두지 않는다 (결계 위성의 "딜타임 개방"과 구조를 겹치지 않게).
- 게이지는 **4~5칸**. 지금 채우는 칸만 천천히 식고, **다 채운 칸은 잠겨** 다시 내려가지 않는다. 칸이 잠길 때 성벽에 금이 가고 증기·불꽃이 새어 나와 진행이 보인다.
- 패턴 하나에 주탄 **2~3개**: 길 중간에 작은 주탄, 패턴 끝에 큰 주탄 (두 배 과열). 잘하는 사람은 놓치지 않고 몰아쳐 빨리 끝내고, 못해도 칸이 쌓여 진행이 멈추지 않는다.
- 마지막 칸이 차면 **대폭발** — 성벽이 안에서부터 터져 무너진다 (기존 보스의 "코어 노출 → 한 방"을 대신하는 이 보스만의 끝).
- 클리어 시간 목표: 잘하는 플레이 1분대 초반, 평균 2~3분 ([RULES.md](RULES.md) 6장). 칸 수·식는 속도·주탄 과열량으로 맞춘다.

## 4. 타격점과 주탄 되돌리기

- **패턴 중에는 저장소가 닫혀 있다.** 돌진·차지·동조 일격은 성벽에 튕기고(피해 없음) 조준점·붉은 윤곽선이 뜨지 않는다.
- **주탄을 패리한 순간에만** 저장소의 투입구가 열려 표적이 된다 (조준 중 붉은 윤곽선 + 조준점). 리버스 드라이브(또는 PERFECT면 되돌린 주탄)가 투입구에 닿으면 과열.
- 리버스 드라이브가 지나간 길의 지형 탄은 지워진다 (RULES 7장). 되꽂으러 올라가는 길이 그대로 다음 길이 된다.
- 동조(퍼펙트 회피) 강화는 보라 줄넘기에서만 얻는다. 동조 일격도 패턴 중에는 성벽에 막힌다.

## 5. 무대

- 성벽: 화면 가로를 다 덮는 높은 벽 (보스는 화면을 채우게 크게, RULES 6장). 표면에 축전 셀·배관·투입구, 과열될수록 붉게 달아오른다.
- 발사구가 성벽을 따라 줄지어 있고, **지휘자 하나가 화면 전체의 모양**을 정한다 (발사구는 같은 박자로 쏘는 연출).
- 플레이어는 발판에서 이륙해 성벽 아래 넓은 공간에서 싸운다. 위로 갈수록 탄이 짙고 주탄도 가깝다.

## 6. 탄막 (지형 탄 = 잔탄, 기회 탄 = 금)

후보 (지휘자 패턴, 모두 안전 통로를 보장):
- **내려오는 성벽 줄**: 잔탄으로 된 가로줄이 한 칸씩 틈을 두고 내려온다. 틈의 자리가 줄마다 바뀌어 지그재그 길이 생긴다. 줄 사이 틈마다 주탄.
- **물결 띠**: 좌우로 출렁이는 잔탄 띠 두세 겹이 내려온다. 출렁임이 엇갈리는 곳이 길.
- **나선 팔**: 성벽 가운데에서 천천히 도는 잔탄 팔. 팔 사이를 따라 돌아 올라가면 끝에 큰 주탄.
- **격자 조이기**: 잔탄 격자가 내려오며 칸이 좁아진다. 칸을 갈아타며 올라간다.
- 미로 국면(지형 빽빽, 주탄 드묾)과 결투 국면(지형 거의 없음, 금빛 연사)을 번갈아 낸다. 지형 탄의 화면 점유는 30~40% 상한.

## 7. 보라: 줄넘기

- 성벽에서 내려온 **보라 광선 한 줄**이 경기장을 가로로(또는 세로로) 쓸고 지나간다. 리듬에 맞춰 넘는다 (돌진 무적으로 통과, 퍼펙트 회피면 흡수 → 동조).
- 한 번에 한 줄만 (보라 둘 금지). 빠르기·간격이 점점 짧아지는 연속 줄넘기.
- 압착(근접)과 겹치지 않는다 (보라 + 근접 금지).

## 8. 근접: 압착 (전장 좁히기)

- 성벽 양옆(또는 위)에서 **거대한 판**이 밀려 나와 전장을 좁힌다. 근접 규칙(RULES 3.3) 그대로: 빠른 준비 동작 → 멈춰 경고 약 1초(요격 가능) → 밀고 들어옴(요격 가능).
- **요격하면** 판이 튕겨 원래 자리로 돌아간다.
- **못 쳐내면** 판이 그 자리에 박혀 전장이 좁아진 채 **한동안(예: 12~15초) 유지**되다가 천천히 물러난다. 좁아진 동안 미로가 더 빡빡해진다.
- 판에 맞으면 피해 (2보스 프레스와 같은 결: 패리하면 막기는 했지만 밀려난다).
- 탄막 패턴과는 함께 나와도 된다 (근접 중 탄은 괜찮다, 2026-10-23 결정). 줄넘기(보라)와는 겹치지 않는다.

## 9. 규칙 점검 (RULES.md)

| 규칙 | 이 보스 | 판정 |
|---|---|---|
| 색 언어 (금·주황·보라·진홍) | 지형 = 주황 잔탄, 주탄 = 금, 줄넘기 = 보라, 압착 = 진홍 | 지킴 |
| 근접 경고 = 요격 가능 구간 | 압착이 그대로 따른다 | 지킴 |
| 보라 + 근접 금지 / 보라 둘 금지 | 줄넘기는 한 줄, 압착과 따로 | 지킴 |
| 동시 패턴 1~2개 | 지휘자 탄막 + (압착 또는 줄넘기) | 지킴 |
| 멍때림 금지 | 생존 구간 사이에 쉬는 틈을 짧게 | 구현 때 점검 스크립트로 확인 |
| 진행할수록 사나워짐 | 잠긴 칸 수에 따라 패턴·탄 속도 상승 | 지킴 |
| 새 보스 탄막 구조 (지형 + 기회 탄, 드라이브가 길을 뚫음) | 그대로 | 지킴 |
| 보스 구조: 외부 시스템 → 개방 → 코어 | **과열 게이지가 체력, 코어 단계 없음, 대폭발로 끝** | **예외 — 승인 필요 (10장)** |
| 표적 표시: 차지·조준 중 붉은 윤곽선 | 패턴 중에는 표적이 없다 (닫힘). 주탄 패리 순간에만 열림 | 사용자 결정 (2장) — 규칙에 "보스가 표적을 닫는 구간" 추가 필요 |
| 체력 게이지 링 | 과열 게이지가 대신한다 (성벽의 달아오름 + 칸 표시) | 모함처럼 예외로 적을지 결정 필요 |

## 10. 남은 질문

1. 보스 구조 예외 승인: 외부 시스템·코어 단계 없이 **과열 게이지 = 체력, 대폭발로 끝** — 괜찮은가?
2. 과열 칸 수 (4 또는 5), 칸이 잠기는 연출 (금·증기·셀이 하나씩 터짐 중).
3. 압착 판의 방향: **양옆**에서 좁혀 오는가, **위에서** 내려오는가 (위에서면 주탄과의 거리가 짧아져 오히려 쉬워질 수 있다), 둘 다인가.
4. 압착이 박혀 있는 시간 (12~15초 제안).
5. 이름 (가칭 "축전 방벽") 과 획득 코어.
