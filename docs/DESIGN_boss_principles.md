# 보스 설계 원칙 + 지금까지의 보스 회고

> 상태: 2026-10-18. 결계 위성(v0.62)이 플레이어들에게 가장 재밌다는 평을 받은 뒤 정리했다.
> 관련: 기획 전반 [PLAN_colossi.md](PLAN_colossi.md) · 결계 위성 [BOSS_satellite.md](BOSS_satellite.md) · 사운드 [SOUND.md](SOUND.md)
> 새 보스 기획서를 쓰거나 기존 보스를 고칠 때 **3장 체크리스트**부터 채운다.

## 1. 결계 위성이 좋았던 이유 (플레이어 평)

- 패턴은 압도적으로 보이지만 실제로는 크게 어렵지 않다.
- 실드를 깨서 딜타임을 여는 쾌감이 있다.
- 딜타임은 탄막의 바다라서, 패리를 못 하면 리스크가 있다. 그냥 주어지지 않는다.

## 2. 원칙

### 2.1 보이는 위협 ≫ 실제 판정
화면을 채우는 빛무리와 잔광을 두고, 실제로 맞는 곳은 가는 중심선만 둔다. 플레이어는 "저걸 뚫었다"고 느끼는데 난이도는 낮다.
이게 억울하지 않으려면 세 가지가 필요하다.
- **색 언어가 확실하다**: 금 = 패리, 보라 = 회피, 주황 별 = 잔탄.
- **예고가 분명하다**: 회전 방향 점선, 단계적으로 늘어나는 격자.
- **판정이 일관된다**: 빛무리는 절대 맞지 않는다.

### 2.2 긴장 → 해방 두 박자가 보스의 뼈대
- 막고 버티는 국면과 몰아치는 국면을 뚜렷이 가른다. 대비가 클수록 해방의 쾌감이 크다.
- **해방은 타이머나 체력 소모가 아니라 플레이어의 행동으로 연다.** 결계 위성은 퍼펙트 회피 → 동조 → 금 3번으로 연다.
- 여는 과정의 진행이 **눈에 보여야** 한다 (금이 하나씩 는다).
- 한 번으로 끝나지 않고 **되풀이된다**: 열림 → 닫힘 → 다시 긴장.

### 2.3 해방 중에도 실력 시험
- 딜타임은 공짜 딜이 아니라 기회의 바다다. 잘하면 딜이 폭발하고, 못하면 맞는다.
- 보상이 실력에 비례하므로, 못하는 사람도 버틸 수 있고 잘하는 사람은 실력을 드러낼 수 있다.

### 2.4 적의 공격 = 내 연료
- 모든 위협이 기회로 바뀔 길을 가진다: 주탄은 패리, 근접은 요격, 패리 불가는 퍼펙트 회피로 동조.
- 순수한 장애물(피하기만 하고 아무것도 얻지 못하는 것)은 줄인다.

### 2.5 손 쓰임을 번갈아
- 갈래가 다른 패턴을 번갈아 낸다 (회피 ↔ 패리 ↔ 요격). 같은 손 쓰임이 연달아 나오지 않게 해서 피로 대신 리듬을 만든다.

### 2.6 보스마다 학습 역할이 있다 — 구조를 복사하지 않는다 (2026-10-18 사용자 정정)
- 관측자 = 기본 메커니즘을 한 번씩 보여 주며 기본 조작에 익숙해지게 · 탄막 요새 = 패리·돌진패리 · 크라켄 = 요격 · 결계 위성 = 회피·동조.
- **모든 보스가 "특정 행동 → 딜타임 개방"을 답습하면 예측 가능해진다.** 딜타임 개방은 결계 위성의 것으로 둔다.
- 대신 보스마다 **부목표**를 준다: 패리 말고도 집중할 목표 + 그에 따른 보상. 조건
  1. 그 보스가 가르치는 동사만으로 달성한다 (새 규칙을 따로 가르치지 않는다. 튜토리얼 장을 늘리지 않는다).
  2. 진행·보상이 한눈에 보인다 (보고 "쳐 보고 싶게" 만든다).
  3. **보상의 형태가 보스마다 다르다** (전장 바꾸기 / 반격 / 보너스 / 딜타임).
  4. 부목표는 선택이다. 안 해도 기본 딜(리버스 드라이브)로 깰 수 있고, 하면 크게 빨라진다.

## 3. 새 보스 체크리스트

| 질문 | 결계 위성의 답 |
|---|---|
| 긴장 국면의 압도적 연출은? 실제 판정은 얼마나 얇은가? | 8줄기 폭풍·격자·결계 벽 / 가는 중심선 |
| 해방을 여는 **행동**은? (핵심 동사) | 퍼펙트 회피 → 동조 일격 3번 |
| 여는 진행이 어떻게 보이는가? | 결계의 금 |
| 해방 중의 리스크는? | 금빛 탄막의 바다 |
| 해방이 되풀이되는가? 닫힐 때 예고는? | 7초 열림, 깜빡임 후 닫힘, 2.5초 봉인 |
| 순수 장애물인 공격이 남아 있는가? | 없음 (패불기도 동조 자원) |
| 손 쓰임이 번갈아 나오는가? | 패불기 ↔ 탄막 교대 |

## 4. 회고: 지금까지의 보스

공통 반성부터 적는다.
- **페이즈를 체력 단계로 설계했다.** 외부 시스템 → 개방 → 코어는 깎으면 넘어가는 소모전이다. "내가 열었다"는 순간이 한 번(개방)뿐이고, 그 뒤 코어 페이즈는 같은 일의 반복이 된다.
- **근접·패리 불가를 의무 항목으로 넣었다** (PLAN_colossi 원칙 8). 그래서 핵심 고리에 섞이지 않고 드물게 나오는 장애물로 남았다.
- **옛 규칙 위에 덧댔다.** 패리 개편, 동조, 튕김 규칙이 나중에 생겼고, 초반 보스는 그 규칙을 전제로 짜이지 않았다. 외형도 그래서 뒤처졌다 (v0.62에서 일부 보완).

### ① 관측자 — 튜토리얼 보스
- **좋았던 점**: 모든 동사(돌진·차지·패리·요격·회피)를 한 번씩 만지게 한다. 팔 휘두르기 요격이 첫 "큰 한 방"을 준다.
- **아쉬운 점**
  - 외부 시스템 4개 → 장갑 → 코어로 이어지는 일직선 소모전이다. 표적을 어떤 순서로 부숴도 결과가 거의 같다.
  - 코어 페이즈의 변화가 적다 (PLAN_colossi에서도 지적).
  - 융해 분출과 눈 레이저는 피하기만 하는 장애물에 가깝다.
- **방향 (가볍게, 5장)**: 부위를 골라 부수면 그 부위의 공격이 사라지는 것을 확실히 보여 준다 (쏘려던 포가 터짐, 팔이 축 늘어짐). 팔부터면 근접이, 포대부터면 탄막이 준다. ~~팔 요격 → 휘청 → 딜타임~~ (딜타임 복사 금지로 철회)

### ② 탄막 요새 — 패리 중심
- **좋았던 점**: 대부분의 탄이 연료다 (주탄은 패리, 잔탄은 흡수, 유도탄은 크게 되돌리기). 2.4 원칙을 가장 잘 지킨다.
- **아쉬운 점**
  - 해방 박자가 없다. 처음부터 끝까지 비슷한 밀도로 패리하며 깎는다.
  - 보이는 위협과 실제 판정이 같다. 화면이 실제로 위험하게 차 있어서 "압도적이지만 할 만하다"보다 "빡빡하다"는 인상이다.
  - 반응로 폭주는 코어 페이즈에 붙은 추가 공격일 뿐, 얻어 내는 순간이 아니다.
  - 프레스와 동심원은 드문 의무 항목이다.
- **방향 (5장)**: 크고 빠른 금색 포탄을 돌진패리로 되받으면 쏜 포대로 되돌아가 큰 피해 + 포대 잠시 침묵. ~~유도탄을 배기구에 되돌려 과열 → 딜타임~~ (새 메커니즘 학습 부담·딜타임 복사로 철회)

### ③ 크라켄 — 요격 중심 (v0.63에서 손봄)
- **좋았던 점**: 결계 위성에 가장 가깝다. 요격으로 촉수를 박살 내면 그 패턴도 사라진다. 촉수 연속 공격의 예고(순번)도 잘 읽힌다.
- **아쉬웠던 점**: 근접이 너무 안 나왔다 (확률 30% + 탄이 걷히길 기다림 + 끊긴 촉수 제외 → 1분에 2번 남짓). 방어막은 체력 문턱에서 한 번 깨지고 끝, 촉수 보상은 금방 잊혔다. 눈알이 맥없게 생겼다.
- **바꾼 것**
  - 순서 고정: 탄막 → 근접 (v0.64, 방전 그물은 가끔 탄막 차례를 대신). 연속 내려치기의 첫 타는 플레이어를 따라가고, 뒤 타들은 그 자리에 떨어진다.
  - 촉수는 요격 2번이 쌓이면 끊긴다 (강한 요격은 1번). 연속 성공을 요구하지 않는다.
  - ~~잘린 집게를 쳐서 눈알에 꽂아 방어막 깨기~~ (v0.63~0.66 시험 후 철회 → **방어형 보스용으로 보류**): 연속 요격으로 집게가 한꺼번에 떨어지면 너무 빨리 깨졌고, 날아간 집게가 화면 밖에서 꽂혀 재미가 덜했다.
  - **방어막 = 판 여섯 장, 촉수 하나 = 판 하나** (v0.67): 촉수 뿌리에서 판으로 빛나는 동력선이 이어진다. 촉수를 끊으면 그 판이 꺼져 떨어진다 (처음 한 번만). 예전에 "표적이 여섯 개라 정신없었던" 문제는 쉬는 촉수에 판정이 없고 공격 중인 촉수만 요격할 수 있어서 생기지 않는다 — 늘 하던 요격의 결과가 판으로 보일 뿐이다.
  - **방어막 = 방어력**: 리버스 드라이브는 늘 방어막을 뚫고 코어에 딜이 들어가지만, 판이 남아 있을수록 덜 들어간다 (50% → 100%). 플레이어의 일격은 판을 깎지 못한다. 판이 다 떨어지거나 코어가 100까지 깎이면 깨진다.
  - 보여 주는 법: 판 개수 / 상처 입은 촉수의 선·판이 깜빡임 / 뚫은 빛줄기의 깊이 (게이지 같은 UI 없이).
  - 몸통: 문어(눈이 둘인 동물)에서 **거대 기계 오징어**로 (v0.67). 기운 외투막·지느러미·물결치는 발광등으로 정물화처럼 보이지 않게. 촉수는 길게 늘어졌다가 끝이 올라와 플레이어를 겨눈다.
  - 눈알: 둥근 기계 눈 (포탈2 코어처럼 강철 구체 + 발광 홍채 고리 + 렌즈, 광학부가 플레이어 쪽으로 굴러간다). 뱀눈·불꽃 눈은 징그럽거나 이질적이라 철회.
  - 패리 불가 = 눈알 쓸기: 동공에서 나온 광선 한 줄기가 경기장을 한 바퀴 쓸고, 도중에 동심원 하나 (방전 그물·눈알 동심원을 대신, v0.66).

### ④ 결계 위성 — 회피 중심 (기준점)
- 2·3장의 답이 이 보스다.
- **남은 숙제**: 잔탄 부담이 다소 크다 (로그상 피격 원인 1위). 2단계 콘텐츠(프리즘·고리 조이기 등)는 미구현.

## 5. 정리: 보스별 부목표 (제안 포함)

| 보스 | 학습 | 부목표 | 보상의 형태 | 상태 |
|---|---|---|---|---|
| 관측자 | 기본 조작 | 부위를 골라 부수기 (팔 = 근접 사라짐, 포대 = 탄 줄어듦) | 전장을 내가 바꾼다 | 제안 (일부는 이미 코드에 있으나 체감되지 않음) |
| 탄막 요새 | 패리·돌진패리 | 크고 빠른 포탄을 돌진패리로 되받기 → 쏜 포대로 되돌아감 | 반격 (큰 피해 + 포대 잠시 침묵) | 제안 |
| 크라켄 | 요격 | 촉수를 끊어 동력선에 매달린 방어막 판 떼어 내기 | 방어력 약화 → 코어 노출 | v0.67 구현 |
| 결계 위성 | 회피·동조 | 동조 일격으로 결계에 금 3번 | 딜타임 개방 | v0.51~ |

**공통 (v0.63)**: 껍질이 다 벗겨진 코어는 한 대면 터진다. 그렇게 **보이게** 한다 — 주변은 검게 그을리고, 코어는 작고 하얗게 달아올라 떨리며 갈라지고 전기가 튀고 경보 고리가 퍼진다 (관측자·탄막 요새).
