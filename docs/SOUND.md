# 사운드 체계

> 상태: v0.62 (2026-10-16). 효과음은 에셋 없이 코드로 합성한다 (`scripts/sfx.gd`). 배경음악은 `assets/music/bgm.wav` (`tools/make_bgm.py` 로 합성, `scripts/music.gd`).
> 새 효과음을 넣거나 기존 소리를 붙일 때는 이 표를 먼저 보고 **어느 갈래인지** 정한다.

## 1. 원칙: 소리의 갈래

| 갈래 | 느낌 | 만드는 법 | 쓰는 곳 |
|---|---|---|---|
| **보상 (쾌감)** | 크고 선명하고 **높다**. 맑게 울린다 | 높은 사인파 화음(1~5 kHz) + 짧은 잡음 어택, 큰 보상은 아래에 낮은 붐 | 패리 성공, PERFECT, 패리 드라이브·요격 적중, 완전 동조, 결계·장갑 금, 코어 노출, 치료, 차지 완료 |
| **실패·막힘** | **둔탁하다**. 낮게 '텅', 울림 없이 바로 끊긴다 | 낮은 사인(150~400 Hz)이 아래로 떨어지며 빨리 감쇠 | 방어막·결계에 튕김(피해 없음), 근접공격 패리(밀려나기만), 피격, 잔탄 긁힘 |
| **이동·회피** | **쉬익** 바람 소리 | 잡음을 저역 통과 필터로 거르며 차단 주파수를 위로 쓸어 올림 | 돌진, 차지 강습·리버스 드라이브 출발, 발사 |
| **중립 타격** | 짧고 가볍다 (보상보다 작게) | 높은 틱 + 짧은 잡음 / 중간 '쿵-챙' | 일반 돌진 적중, 반사탄 적중, 차지 강습 적중 |
| **적** | 낮거나 기계적이다. 플레이어 보상음과 음역이 겹치지 않게 | 낮은 붐, 톱니파 웅웅거림, FM 삑 | 적 탄 발사, 패리 불가 발사, 발 구르기·프레스, 부위 파괴 |

**규칙**
- **약해도 성공은 성공음.** 일반 패리 드라이브는 약한 공격이지만 '맞혔다'이므로 보상 갈래(작고 밝은 `hit_drive`)를 쓴다. 둔탁한 소리는 "피해가 안 들어갔을 때"만.
- **세기 = 크기·높이·길이.** 같은 갈래 안에서 공격이 셀수록 더 크고 길고 붐이 깊다 (돌진 `hit_light` < 차지 `hit_charge` < 패리 드라이브 `hit_drive` < PERFECT `hit_perfect`).
- **색 = 음색.** 금빛(패리) = 금속 차임, 청록(동조·퍼펙트 회피) = 빠르게 오르는 3화음 반짝임 `sync`, 보라(패리 불가) = 낮은 전기 웅웅 `beam`.
- 한 순간에 보상음은 두 겹까지 (예: `hit_perfect` + `perfect`/`sync`). 더 겹치면 뭉개진다.

## 2. 효과음 목록 (sfx.gd)

| 이름 | 갈래 | 소리 | 붙은 곳 |
|---|---|---|---|
| `parry` | 보상 | 맑은 금속 차임 | 패리 성공, 돌진패리, 반사 |
| `perfect` | 보상 | 높은 차임 + 낮은 붐 | PERFECT 패리, 장갑 완파, 코어 노출 완료, FTL 도약, 승리 |
| `hit_drive` | 보상 | 밝은 '쨍' (작게) | 일반 패리 드라이브 적중, 요격 |
| `hit_perfect` | 보상 | 큰 붐 + 높은 쨍 + 잔향 | PERFECT 드라이브·완전 동조 차지 적중 (`_perfect_impact`) |
| `sync` | 보상 | 오르는 3화음 반짝임 | 퍼펙트 회피(작게)·강한 퍼펙트 회피, 완전 동조 차지 출발·적중, 동조 일격 |
| `crack` | 보상 | 유리 갈라지는 파열 + 낮은 받침 | 결계에 금, 장갑·부위 손상 단계 |
| `open` | 보상 | 위로 쓸어 올리는 상승음 | 코어 노출·결계 열림 |
| `heal` | 보상 | 부드러운 높은 두 음 | 잔탄 긁힘 치료 |
| `charged` | 보상 | '띵-딩' 올라가는 두 음 | 차지 완료 |
| `deflect` | 실패 | 낮은 '텅' | 방어막·결계에 튕김(피해 없음), 근접공격 패리(밀려나기만) |
| `hurt` | 실패 | 일그러진 하강음 | 피격 (셀 손실) |
| `graze` | 실패 | 짧은 '치익' | 잔탄 긁힘 |
| `dash` | 이동 | 짧은 쉬익 | 일반 돌진, 돌진패리 |
| `dash_big` | 이동 | 길고 큰 쉬익 | 차지 강습·리버스 드라이브 출발, 발사, FTL, 적 팔 휘두르기 |
| `hit_light` | 중립 | 짧은 '틱' | 일반 돌진 적중, 반사탄 적중 |
| `hit_charge` | 중립 | 단단한 '쿵-챙' | 차지 강습 적중, 요격(받침) |
| `bolt` | 적 | FM 삑 | 적 탄 발사, 용암 분출 |
| `beam` | 적 | 낮은 전기 웅웅 | 패리 불가 광선·고리·벽 발사 |
| `stomp` | 적 | 낮은 붐 | 발 구르기, 프레스, 큰 파괴의 받침 |
| `break` | 적/보상 받침 | 잡음 + 하강음 | 부위 파괴, 장갑 완파, 용암 낙하 |
| `land` | 기타 | 낮은 '툭' | 착지, 부활, 잔해 낙하 |
| `win` | 보상 | 장화음 + 붐 | 코어 파괴(승리) |

## 3. 배경음악

- 차분한 일렉트로닉 루프: 112 BPM, A 단조, 16마디 34초 (Am – F – C – G 를 두 마디씩 두 바퀴).
- 층: 부드러운 패드 · 8분음 베이스(박마다 사이드체인 펌핑) · 오프비트 하이햇 · 킥 · 5마디부터 16분 아르페지오 · 9마디부터 2·4박 클랩. 끝과 처음이 이어진다.
- 게임 안 음량 −16 dB (효과음보다 한참 작게). 메뉴·일시정지 중에도 흐른다.
- 다시 만들기: `python tools/make_bgm.py` → Godot 가져오기(반복 재생 설정은 `bgm.wav.import` 의 `edit/loop_mode=2`).
- 앞으로: 스테이지마다 다른 곡 / 보스 페이즈에 따라 층을 더하는 방식은 미정.
