# Parry Pierce 돌진 개편 기획서 (브랜치 `dash-rework`)

> 상태: **기획 — 5장 결정 대기**. 수치는 시작값이며 플레이 테스트로 조정.
> 기준 버전: v0.20 (main). 이 브랜치의 빌드는 main과 섞이지 않도록 프리릴리즈(`v0.30-a1`, `a2` …)로 올린다.

---

## 1. 목표

1. **돌진을 자원 없는 기본기로**: 게이지를 없애고 쿨다운만 남긴다. 돌진 하나가 이동·회피·공격을 겸한다.
2. **평타는 쉽게, 하지만 느리게**: 돌진만으로도 피해는 들어가지만 보스 체력이 크게 늘어 평타만으로는 오래 걸린다.
3. **패리는 크게 한 방**: 패리 돌진 피해를 크게 올려 잘 하면 빨리 깬다.
4. **읽히는 피해**: 체력바 없이 부서지는 모습으로 남은 체력을 보여 준다.
5. **도트 그래픽**으로 재설계 (기계 부분이 끝난 뒤 별도 단계).

새 핵심 루프:
```
돌진(무제한, 쿨다운) 으로 붙어서 평타 1 / 꾹 눌러 차지 3
  ├ 탄 → 우클릭 패리 → 슬로우 조준 → 패리 돌진 12 (큰 한 방)
  ├ 팔 휩쓸기 → 차지 돌진으로 정면 충돌 = 받아치기 (그 팔 관절에 즉시 8 + 팔이 밀려나 멈춤)
  │            → 일반 패리 = 피해 없이 튕겨나기만 (보상 없음)
  └ 공격이 스치는 순간 돌진 = 퍼펙트 회피 → 다음 차지 강화(빨라지고 피해 2배)
적중하면 입사각=반사각으로 튕겨난다. 몸에 닿거나 맞으면 목숨 −1 + 스턴 추락.
```

## 2. 평가 — 먼저 짚어야 할 점

### 2-1. 높이 = 생존 규칙이 무너진다 (가장 큰 영향)
지금 게임의 뼈대는 "스스로는 올라갈 수 없고, 높이는 패리와 직격 반동으로만 번다 → 용암이 압박"이다. 게이지가 그 제한 장치였다.
돌진이 무제한이 되면 위로 계속 돌진해서 높이를 공짜로 번다. 현재 수치로 계산하면 위로 한 번 돌진할 때 약 560px + 남은 관성으로 약 550px, 합쳐 1,100px가 오르고, 쿨다운 0.7초 안에 다시 돌진할 수 있다. **용암은 스턴 추락 때만 위협**이 된다.

선택지 (5장 결정 1):
- **A. 받아들인다 + 위쪽 관성만 줄인다 (추천)**: 위로 향한 돌진은 끝난 뒤 관성을 남기지 않는다. 그래도 연속 돌진으로 초당 약 650px씩 오를 수 있으므로 높이는 더 이상 귀한 자원이 아니다. 대신 용암 압박은 "피격 → 스턴 추락"에서 나오고, 천장이 위를 막는다. 돌진 쿨다운 동안 공격을 버티는 것이 새 긴장 요소가 된다.
- B. 연속 돌진 과열: 2초 안에 연속으로 쓸수록 쿨다운이 0.7 → 1.0 → 1.4초로 늘어난다. 높이 제한은 남지만 규칙이 하나 더 생긴다.
- C. 위쪽 돌진 거리 자체를 60%로: 가장 강하게 막지만 조작이 방향마다 다르게 느껴진다.

### 2-2. "퍼즐처럼 구조를 뚫는 게임" → "체력을 깎는 게임"
기획서 첫 줄의 정체성("보스 HP를 깎는 게임이 아니라 방어 구조를 뚫는 게임")이 바뀐다. 블록깨기를 없애고 체력 많은 코어 하나로 가면 조준·순서 판단은 줄고, 대신 **언제 패리로 크게 칠지**의 리듬 게임이 된다. 요청 방향과 맞으므로 진행하되, 단조로워지지 않도록 **부위(포대·관절)를 먼저 부숴야 가슴이 열리는 단계 구조는 유지**하는 것을 추천한다 (결정 3).

### 2-3. 돌진이 무적 + 공격을 겸하면 "돌진 연타"가 최적해가 될 수 있다
- 돌진 중엔 무적이고, 적중하면 0.9초 무적으로 튕겨난다. 쿨다운이 짧으면 무적 상태로 계속 때리는 플레이가 된다.
- 대책: 쿨다운 0.7초(돌진 시작 기준, 무적 비율 약 40%), **적중해도 쿨다운은 초기화하지 않는다**(지금은 적중 시 초기화). 대신 패리는 적중 직후 바로 가능하다.
- 퍼펙트 회피 성공 시에만 돌진 쿨다운을 즉시 초기화해, 위험을 감수한 쪽에 템포 보상을 준다.

### 2-4. 모든 방향 반사는 아래로 떨어지는 반사가 생긴다
아래에서 위로 들이받으면 그대로 아래(용암 쪽)로 튕긴다. 요청대로 순수 반사로 가되, 돌진이 무제한이라 복구는 가능하다. 실제로 해 보고 불편하면 v0.17처럼 아래쪽만 보정하는 안을 다시 꺼낼 수 있다.

### 2-5. 접촉 피해 + 목숨 3개는 빡빡할 수 있다
반사로 튕겨난 뒤 다른 부위에 닿는 일이 잦아진다. 적중 직후 0.9초 무적이 있어 대부분은 막히지만, 목숨이 3개라면 체감 난도가 많이 오를 수 있다. 우선 3개로 두고 해 보고 조정하는 것을 추천한다 (결정 5).

### 2-6. 도트 그래픽은 내가 화면으로 확인할 수 없다
헤드리스 실행에서는 화면이 렌더링되지 않는다(창 금지 규칙 유지). 그래서 도트 작업은 이렇게 검증한다:
- 스프라이트·팔레트를 **PNG로 직접 만들어 내가 이미지로 보고** 확인한다.
- 게임 화면은 같은 그리기 규칙으로 **목업 이미지를 합성**해 먼저 보여 드리고, 실제 게임 화면은 직접 확인 부탁드린다.
- 기계 변경과 섞으면 무엇 때문에 이상한지 구분이 어려우니 **별도 단계**로 나눈다.

## 4. 상세 기획

### 4-1. 입력

| 입력 | 동작 |
|---|---|
| 좌클릭 짧게 (0.15초 미만에 뗌) | 뗄 때 마우스 방향으로 **돌진** |
| 좌클릭 꾹 | 0.15초부터 공중에서 거의 멈춰 차지 (떨림). 0.6초에 완료(빛남 + 사거리 레이저). 완료 후 1.3초 지나면 자동 발사 |
| 좌클릭 뗌 | 다 모았으면 **차지 돌진**, 덜 모았으면 **일반 돌진** (모은 시간이 버려지지 않는다) |
| 우클릭 / Space | **패리** (일반 0.2초, PERFECT 0.07초) |
| 패리 성공 후 | 슬로우 조준 1.4초(PERFECT 1.9초). 우클릭을 떼거나 아무 버튼 → 패리 돌진 |
| 발판 위 | 좌클릭 = 발사 (지금과 같음) |

> 돌진이 "뗄 때" 나가므로 아주 짧은 지연이 있다 (v0.19까지와 같은 방식). 대안은 "누르는 즉시 돌진, 계속 누르고 있으면 돌진이 끝난 뒤 차지"인데, 차지 전에 항상 한 번 이동하게 되어 위치 잡기가 어려워 추천하지 않는다 (결정 2).

### 4-2. 돌진

| 항목 | 값 |
|---|---|
| 속도·시간 | 2000 × 0.28초 = 약 560px (지금 회피와 같음) |
| 쿨다운 | **0.7초** (돌진 시작부터). 차지 돌진도 같은 쿨다운 |
| 무적 | 돌진 내내 |
| 공격 | 표적(부위·코어)에 닿으면 피해 1 → 반사 튕김 + 0.9초 무적 |
| 적중 시 | 쿨다운 **유지** (초기화 안 함). 패리는 즉시 가능 |
| 위쪽 돌진 | (결정 1-A일 때) 끝난 뒤 위쪽 관성을 남기지 않는다 |
| 쿨다운 표시 | 기체 주변 얇은 링이 차오름 + 쿨다운 중 노즐 화염이 약해짐 |

### 4-3. 차지

| 항목 | 값 |
|---|---|
| 모으기 | 0.6초 (퍼펙트 회피 버프 시 0.3초) |
| 차지 돌진 | 3600 × 0.22초 = 약 790px, 피해 **3** (버프 시 **6**) |
| 받아치기 | 팔이 휩쓰는 중(판정이 켜진 동안) 차지 돌진이 팔에 닿으면: 그 팔 **관절에 즉시 8**, 팔은 지금의 패리처럼 밀려나 1초 멈춤(관절 노출), 플레이어는 반사로 튕겨나며 큰 히트스톱·금색+주황 임팩트 |
| 일반 돌진이 팔에 닿으면 | 무적으로 통과 (스치면 퍼펙트 회피) |

### 4-4. 패리

| 대상 | 결과 |
|---|---|
| 탄 | 지금과 같다: 슬로우 조준 → 패리 돌진 (피해 12 / PERFECT 16) |
| 팔 휩쓸기 | **피해 없음 + 반대 방향으로 튕겨남** (팔에서 멀어지는 쪽, 속도 약 1100, 무적 0.5초). 조준·패리 돌진 없음. 팔은 멈추지 않고 그대로 휩쓴다 |
| 레이저 | 패리 불가 (지금과 같음, 돌진 무적으로만 피함) |

### 4-5. 회피

- **일반 회피**: 돌진 무적으로 공격을 통과해도 아무 보상·슬로우·이펙트 없음.
- **퍼펙트 회피** (돌진 시작 후 0.12초 안에 공격이 스침): 다음 차지 ×2·차지 시간 절반(청백 오라, 맞으면 소멸), 추가 무적 0.8초, 청록 슬로우·이펙트(지금 것 유지), **돌진 쿨다운 즉시 초기화**.

### 4-6. 반사 튕김

- 법선 n: 원형 표적은 중심 → 접촉점 방향, 코어는 하트 외곽선의 가장 가까운 변의 바깥 방향.
- 새 속도 = (입사 방향을 n에 대해 반사) × 1350 (패리 돌진 ×1.15). 공기저항·튕김 중 좌우 추진 2배는 유지.
- 표면을 거의 스치듯 맞으면 반사 방향도 표면을 따라 나간다 (자연스러운 결과).

### 4-7. 보스 체력과 진행

| 대상 | 체력 | 비고 |
|---|---|---|
| 포대 ×2 | 24 | 부서질 때마다 탄 +10% (지금과 같음) |
| 팔 관절 ×2 | 24 | 부서지면 팔이 늘어져 휩쓸기 불가 (지금과 같음) |
| 코어 | 160 | 부위 4개를 모두 부수면 가슴이 열리고 코어가 드러남 (결정 3) |

예상 클리어 시간 (대략):
- 잘 하는 플레이: 패리 돌진 약 5초마다 12 + 사이사이 차지 → 초당 약 3.4 → **약 75초**
- 평타·차지만: 초당 약 1~1.5 → **약 3~4분**

### 4-8. 시각 피드백 (체력바 대체)

**부위 (포대·관절)** — 남은 체력 75 / 50 / 25%에서 단계가 바뀐다:
1. 긁힌 자국 + 작은 패임
2. 붉게 달아오른 균열 + 맞을 때 불꽃
3. 장갑 한 조각이 떨어져 나가고 연기
4. 짙은 연기 + 깜빡이는 내부 불빛 → 0이 되면 지금처럼 떨어져 나감

**코어** — 하트 모양 강철 껍질에 싸인 코어. 피해 20%마다 단계가 바뀐다:
1. 매끈한 강철, 리벳, 이음새 사이로 희미한 빛
2. 패임과 긁힘
3. 갈라진 틈으로 코어 빛이 새어 나온다
4. 껍질 판이 휘고 큰 조각이 떨어져 나가 코어가 일부 드러난다
5. 껍질은 뼈대만 남고 코어가 맥동하며 불꽃이 튄다 → 0이 되면 지금의 심장 관통 피날레

공통: 맞을 때마다 흰 번쩍임 + 피해량만큼 큰 파편 + 단계가 바뀌는 순간 짧은 히트스톱·조각 탈락 이펙트.

### 4-9. 몸 접촉

- 돌진 중이 아니고 무적이 아닐 때 표적(부위·껍질/코어)에 닿으면 **목숨 −1 + 스턴 추락** (보스 몸 실루엣 전체가 아니라 지금처럼 표적만 판정).

### 4-10. 삭제되는 것

게이지와 HUD 칸, 0칸 재생, 적중 시 환급, 일반 회피 보상·슬로우, 하트 갑옷 격자·내구도 막대, 부위 체력바, 차지 쿨다운 1.5초.

### 4-11. 도트 그래픽 (별도 단계)

| 항목 | 안 |
|---|---|
| 렌더링 | 기준 해상도 **640×360**으로 그리고 정수배로 키운다 (1280×720 = 2배, 1920×1080 = 3배). 최근접 필터, 위치·꼭짓점 픽셀 스냅. 기체 길이 약 25px, 보스 키 약 1,200px |

## 6. 구현 순서

1. **조작·자원** — 게이지 삭제, 좌클릭 돌진/차지, 우클릭 패리, 쿨다운, 일반 회피 보상 삭제, 퍼펙트 회피 보상 변경
   → 검증: 헤드리스 테스트 (쿨다운, 짧게/꾹, 버프 배율, 쿨다운 초기화)
2. **전투 판정** — 돌진 피해, 반사 튕김, 접촉 피해, 받아치기, 팔에 대한 일반 패리
   → 검증: 반사각 수치 테스트, 받아치기 시 관절 피해·팔 정지, 일반 패리 시 피해 없음·조준 없음
3. **보스 재설계** — 체력 상향, 격자 삭제 → 강철 껍질 코어, 부위·코어 단계별 손상 그림, 체력바 삭제
   → 검증: 단계 전환 테스트 + 그리기 오류 스모크 → 프리릴리즈 `v0.30-a1` (exe만)
4. **도트 기반** — 640×360 렌더링, 팔레트, 픽셀 스냅, 폰트 → 목업 확인 후 `a2`
5. **도트 아트** — 기체·보스·배경·이펙트 스프라이트 → `a3` …

모바일(APK)은 PC 완성 전까지 계속 보류한다.
