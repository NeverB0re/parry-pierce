# Parry Pierce v0.7 기획서 — "용암 위의 공중전"

> 상태: **구현 진행** (4장 결정 확정). 수치는 시작값이며 플레이 테스트로 조정.
> 기준 버전: v0.6 (부위 파괴 + 코어 페이즈)

---

## 1. 목표

1. **실패 규칙을 하나로 만든다**: HP 대신 "용암에 떨어지면 목숨 하나 잃음". 높이 = 생존.
2. **패리를 유일한 주 공격 수단으로 만든다**: 일반 돌진은 회피 전용. 공격은 패리 돌진(주력)과 차지 돌진(보조).
3. **읽기 쉽게 만든다**: 주인공이 크고 잘 보이고, 추진 상태·회피·표적·위험이 색과 모양으로 바로 구분된다.

핵심 루프(유지·강화):
```
패리 → (슬로우·표적 강조) → 패리 돌진으로 표적 타격 → 위로 튕김 → 다시 패리 …
          ↘ 실패/피격 → 스턴 낙하 → 회복 직후 회피 돌진·활공으로 버팀 → 용암 위기
```

## 3. 상세 기획

### 3-1. 주인공: 로켓

| 항목 | 값 |
|---|---|
| 그림 크기 | 길이 약 30px → **약 56px** (머리 끝~노즐) |
| 판정 반지름 | 9 → **12** (그림 크기보다 작게 유지 = 억울함 방지) |
| 머리 방향 | 평소: 마우스 방향으로 회전 (부드럽게, 초당 약 12배 보간). 마우스가 기체 40px 안이면 직전 방향 유지 (떨림 방지) |
| 돌진·튕김 중 | 진행 방향을 바라봄 (지금과 동일) |

**추진기 화염 (직관적 피드백)**: 노즐은 머리 반대쪽.
- 마우스가 **위**(활공): 화염이 **길고 밝게** 타오름 → "버티고 있다". 낙하 상한 **140** (현재 230보다 더 천천히 → 공격을 기다릴 수 있게)
- 마우스가 **옆**: 중간 화염. 낙하 상한 **480** (현재 1100보다 낮춤)
- 마우스가 **아래**: 화염 **짧고 약하게** + 몸 주변에 **속도선** → "떨어지고 있다". 낙하 상한 **1000**, 아래쪽 추진 추가
- 스턴 중: 화염 꺼짐 + 연기 → "조종 불가"를 한눈에

> 화염 길이 = 기본 8 + 34 × max(0, 위쪽 성분). 깜빡임(난수)을 약간 넣어 살아있는 느낌.

### 3-2. 용암과 목숨

| 항목 | 값 |
|---|---|
| 바닥 | y=0 전체가 용암. 표면 출렁임 + 빛 + 열기 아지랑이 |
| 위험 경고 | 높이 400px 아래로 내려가면 화면 아래쪽이 붉게 물듦 (가까울수록 진하게) |
| 목숨 | 3개 (HUD 왼쪽 위 가면 3개를 그대로 목숨으로 사용) |
| 용암에 빠지면 | 목숨 −1, 큰 물보라·불꽃·지글 소리 → **재출격** |
| 재출격 | 시작 위치에 발판이 **용암에서 솟아오름** → 1.5초 무적 → 첫 돌진 = 발사 (시작과 동일) |
| 진행 유지 | 부순 부위·갑옷은 그대로 유지 |
| 게임 오버 | 목숨 0 → "부서졌다" → 전체 리셋 |

### 3-3. 시작: 발판과 발사

- 시작: 용암 위 작은 발판(폭 약 180px). 발판 위에서는 좌우 이동만 가능.
- **첫 돌진 = 발사**: 방향과 관계없이 거의 위로 솟구침 (마우스 좌우로 약간만 기울어짐). 목표 높이는 거인의 어깨 근처(y ≈ −2400).
  - 구현: 위로 1850의 속도, 처음 0.25초는 중력 없음 → 정점 약 y −2400. 게이지는 소모하지 않음.
- 발사 직후 발판이 금 가며 무너져 용암에 가라앉음 (1초).
- 발사 동안은 무적 + 강한 화염 + 카메라가 위로 앞서감.

### 3-4. 스턴 (피격 = 추락 위기)

| 원인 | 결과 |
|---|---|
| 적 공격(탄·팔·충격파)에 맞음 | 스턴 |
| 돌진하지 않고 표적(부위·갑옷)에 닿음 | 스턴 |

| 항목 | 값 |
|---|---|
| 스턴 시간 | **0.6초** (현재 0.35초 경직보다 김) |
| 넉백 | 맞은 방향 반대로 500, 위로 −150 (바로 수직 낙하하지 않게) |
| 스턴 중 | 조작·추진·활공·돌진·패리 불가, 중력만. 화염 꺼짐 + 빙글 회전 + 연기 |
| 회복 | 회복 순간 짧은 "딸깍" 효과음 + 하얀 링 → **즉시 돌진·패리 가능** |
| 피격 무적 | 스턴 + 0.4초 (연속 피격 방지, 반투명 깜빡임) |
| 맞을 때 | **살짝 솟구침** (위로 −380) → 바로 용암으로 곤두박질치지 않음 |
| 안전장치 | 게이지 지급 **없음**. 대신 기본 낙하 속도를 낮춰(아래 3-1) 버티며 다음 공격을 기다려 패리하는 것이 회복 수단 |

### 3-5. 회피 돌진 (일반 돌진)

| 항목 | 현재 | 변경 |
|---|---|---|
| 공격 판정 | 있음 (피해 1) | **없음** — 표적을 그냥 통과 (닿아도 스턴 없음) |
| 사거리 | 2400 × 0.3초 = 720px | **2000 × 0.28초 ≈ 560px** |
| 무적 | 돌진 중 무적 | 유지 |
| 게이지 | 1칸 | 1칸 |
| 표현 | 금빛 막 | **반투명(알파 0.45) + 청백색 잔상 4개 + 휙 소리** → 공격이 아니라 회피라는 걸 바로 앎 |

### 3-6. 게이지 3칸

| 행동 | 비용/효과 |
|---|---|
| 회피 돌진 | −1 |
| 차지 돌진 | −1 (돌진과 같은 비용, 대신 차지 시간이 위험 부담) |
| 패리 성공 | **가득 (3)** |
| 차지·패리 돌진 적중 | +1 환급 (공격이 성공하면 생존력도 오르게) |
| 자연 회복 | **없음** |

### 3-7. 차지 돌진 (보조 공격)

| 항목 | 값 |
|---|---|
| 조작 | 좌클릭 꾹 → **0.6초** 차지 → 떼면 발사 (1단계만). 차지 완료 후 0.5초가 지나면 자동 발사 |
| 피해 | 1 (현재 일반 돌진과 같음) |
| 사거리 | 약 720px (현재 일반 돌진과 같음) |
| 무적 | 돌진 중 + 끝난 뒤 0.5초 |
| 표현 | 차지 중 떨림 + 주황 레이저 사거리 표시 (지금과 같음). 공격 돌진은 **불투명·주황 불꽃 꼬리** → 회피와 확실히 구분 |
| 비교 | 패리 돌진: 피해 3 + 주변 1, 슬로우 조준, 게이지 가득 → 언제나 패리가 더 좋은 선택 |

### 3-8. 탄막 +20%

| 항목 | 현재 | 변경 |
|---|---|---|
| 부채꼴 탄 속도 | 400 | **480** |
| 흩뿌리기 탄 속도 | 220~340 | **264~408** |
| 공격 사이 쉬는 시간 | 1.2~2.2초 | **1.0~1.8초** |
| 부채꼴 연발 간격 | 0.5초 | **0.42초** |
| 발사 직후 감속 출발 | 0.6초 동안 20%→100% | **0.3초 동안 50%→100%** |
| 페이즈 가속 | 부위당 +10%, 코어 +15% | 유지 |

> 패리가 어려웠던 원인은 느린 속도보다 **출발할 때 속도가 변하는 것**(타이밍 예측이 어려움)일 가능성이 큼. 감속 출발을 짧게 줄이는 것이 핵심.

### 3-9. 팔 휩쓸기 개선

| 항목 | 현재 | 변경 |
|---|---|---|
| 휩쓰는 중 팔 모양 | 팔꿈치가 진행 반대쪽으로 크게 꺾임 | **곧게 편 팔** (팔꿈치는 어깨~주먹 선의 55% 지점에 고정) → 관절 위치를 예측 가능 |
| 패리 시 | 0.4초 만에 0.6rad + α 빠르게 회전 | **휩쓸던 반대 방향으로 0.5rad만, 0.7초에 걸쳐 감속하며** 밀려남 |
| 패리 후 | 바로 복귀 | **1.0초 경직**: 팔이 멈추고 팔꿈치 관절이 밝게 빛남 → 패리 돌진으로 노리기 좋은 기회 |
| 복귀 | 0.9초 | 0.9초 (유지) |

### 3-10. PERFECT 패리 슬로우모션

- PERFECT 패리 → 방향 지정(이미 슬로우) → **발사 순간부터 패리 돌진의 타격 판정이 끝날 때까지 시간 0.5배**
- 끝날 때 0.15초에 걸쳐 원래 속도로 (뚝 끊기지 않게)
- 타격하면 히트스톱 후 슬로우 해제
- GOOD 패리는 슬로우 없음 → PERFECT의 보상감을 키움

## 5. 추가 제안 (평가 중 발견)

1. **내려찍기 → 용암 분출** (확정, 4장): 아래에서 솟는 탄막. 낮은 높이에서는 마지막 생명줄(패리 → 게이지 가득 + 패리 돌진)이자 위기.
   - 분출 지점 3~4곳 (하나는 플레이어 바로 아래), 지점마다 용암 덩어리 4개가 0.1초 간격으로 기둥처럼 솟음
   - 덩어리는 중력을 받아 포물선. 초속은 플레이어 높이보다 150px 위까지 닿도록 계산
   - 높이와 상관없이 쓰지만, 낮을수록 자주 씀
2. **색 언어 통일** (메모의 "색조 대비"):
   - 🟦 청백: 내 것·안전 (주인공, 회피 돌진, 방향 지정 레이저)
   - 🟨 금색: **패리할 수 있는 것** (탄, 휩쓰는 팔의 테두리)
   - 🟧 주황 맥동: **노릴 표적** (부위·갑옷 약점·심장)
   - 🟥 빨강: 그냥 위험 (용암, 경고 부채꼴)
   - 현재는 탄·표적·갑옷 테두리가 모두 주황 계열이라 구분이 약함 → 탄을 금색으로 분리
3. **차지로만 받아칠 수 있는 공격** (메모 아이디어): 예) 큰 구체를 천천히 쏘면 패리로는 튕기지 않고 **차지 돌진으로 깨야** 함. 차지 돌진의 존재 이유가 생김. → v0.8 후보
4. **벽 패리** (메모 아이디어): 양쪽 벽에 패리하면 작게 튕겨오름(게이지 회복 없음). 용암 근처에서의 생존 수단. 남용되면 공중전 긴장이 사라지므로 **횟수 제한**(목숨당 3회)이나 쿨다운 필요. → v0.8 후보
5. **표적 화살표**: 방향 지정·차지 중에는 화면 밖 표적 화살표도 같이 밝아지면 조준 결정이 빨라짐.
