# 관측자 리워크 기획서 (1스테이지, 기본 조작 학습)

> 상태: **기획** (v0.79 기준, 사용자 검토 1차 반영). 외형의 큰 틀(헤일로를 진 망토 입은 거인)은 유지하고 디테일을 살린다. 팔 휘두르기는 **검과 방패**로, 바닥 용암 분출은 **헤일로 렌즈 사격**으로, 눈 레이저는 **방패 동심원**으로 바꾼다.

## 1. 지금 무엇이 문제인가

| 문제 | 원인 |
|---|---|
| 바닥 용암 분출이 비직관적이다 | 보스 몸에서 나오지 않는다. 발을 구르면 바닥이 터진다는 인과가 화면에 안 보이고, 시선을 아래로 끌어 흐름이 끊긴다 (요새 기뢰와 같은 문제) |
| 근접이 "팔"이라 읽기 어렵다 | 맨팔을 휘두르는데 팔 어디가 위험한지, 왜 금빛(패리 가능)인지 그림으로 알 수 없다 |
| 패리 불가 공격이 눈 레이저다 | 머리 위 눈에서 가는 선이 나온다 — 작고 멀어서 예고가 약하고, 다른 보스의 패리 불가 공격(요새·크라켄)과 생김새 연결이 없다 |
| 어깨포 표적 원이 그림과 안 맞는다 | 표적 판정이 포신 중간의 원(반지름 55)이라 포대 모양과 겹치지 않는다 |
| 부위를 어떤 순서로 부숴도 결과가 같다 | (회고 4장) 부순 부위의 공격이 사라지는 게 체감되지 않는다 |

## 2. 한 줄 요약

**헤일로를 진 기사형 거인. 검은 요격으로 받아치고, 방패가 모아 쏘는 동심원(보라)은 회피 돌진으로 넘고, 어깨포와 헤일로의 탄은 받아쳐 되꽂는다 — 게임의 동사를 하나씩 정직하게 보여 주는 첫 보스.**

- 학습 역할: **기본 조작** — 돌진·차지·패리→리버스 드라이브·요격·회피 돌진을 한 번씩 (깊이는 다음 보스들이 맡는다)
- 부목표의 보상 형태: **전장을 내가 바꾼다** — 고른 부위를 부수면 그 공격이 눈에 띄게 사라진다 (DESIGN 5장)
- 색 규칙을 처음 가르치는 보스: **금색 = 패리해서 리버스 드라이브로 되꽂을 수 있는 탄** · **진홍 = 근접**(요격으로 받아친다, 패리해도 리버스 드라이브는 없다) · **보라 = 패리 불가**(방패 동심원) · **붉은 원 = 때릴 곳**

## 3. 외형: 헤일로의 기사 (그림 유지 + 디테일)

### 3.1 바뀌는 것
```
          ◯ ◯ ◯  헤일로 렌즈 16개 (금빛) ── 사격 발사점
       ◯    ┌─┐    ◯
     ◯  ▣═══│◉│═══▣  ◯      ▣ 어깨포 (표적: 포대 윤곽 그대로)
        ║ ┌─┴─┴─┐ ║
   검 ━━╋━┥ 가슴 ┝━╋━━ 방패
   (오른손)│ 문  │  (왼손)   ◆ 방패 가운데 수정 = 동심원 발사점
        ╚═╧═════╧═╝
          망토 · 다리
```
- **오른손: 검** — 몸 높이만 한 곧은 장검. 평소엔 어둡고, **휘두를 때만 날이 진홍으로 달아오른다** (근접 경고색, melee_warn 과 같은 색). 금색은 쓰지 않는다 — 근접은 패리해도 리버스 드라이브가 안 되므로. 칼자루 쪽에 붉은 표적(손목 관절).
- **왼손: 방패** — 몸통 절반을 가리는 탑 방패(직선, 모서리 깎음). 가운데에 눈 문양의 수정. **동심원을 모을 때 수정과 방패 테두리가 보라로 차오른다.**
- **어깨포** — 포대 몸체 + 포신을 직선 판으로 다시 그린다. 표적 테두리는 포대 윤곽(다각형)을 따라간다 (지금의 원 대신).
- **헤일로** — 렌즈 16개는 지금처럼 천천히 돌며 플레이어 쪽이 밝다. 쏠 렌즈만 금빛으로 커지며 달아오른다.

### 3.2 살아 있게 (정물화 금지)
- 숨쉬기: 가슴판·어깨가 아주 천천히 오르내린다. 망토 자락이 흔들린다 (지금도 일부 있음).
- 머리와 두 눈이 플레이어를 따라 돈다. 검 끝이 쉴 때도 살짝 플레이어 쪽으로 기운다.
- 방패를 쥔 팔은 쉴 때 몸 앞을 가렸다 내렸다 한다 (막는 기능은 없다 — 아래 7장).
- 부순 부위는 그대로 남는다: 검이 부러지면 손잡이만 남고, 방패가 깨지면 반쪽 방패, 어깨포는 그을린 포좌.

## 4. 패턴

동시에 1~2개, 탄막과 근접은 겹치지 않는다. 1스테이지라 예고가 길고 탄이 느리다.

| 패턴 | 출처 | 동사 | 내용 | 기존 |
|---|---|---|---|---|
| **조준 연사** (시그니처) | 어깨포 | 패리 → 리버스 드라이브 | 포구가 달아오르며 조준선이 따라오고 5갈래 부채꼴 (가운데 3 주탄) | 유지 |
| **흩뿌리기** | 어깨포 | 회피·잔탄 흡수 | 사방으로 고른 틈 | 유지 |
| **헤일로 사격** (새) | 헤일로 렌즈 | 패리·회피 | 렌즈 3~4개가 차례로 달아올라 각각 느린 주탄 한 발을 플레이어에게. 렌즈는 부서지지 않는다 (배경 발사점) | 용암 분출 대체 |
| **검 휘두르기** | 오른손 검 | 요격·회피 | 지금의 팔 휘두르기 흐름(들어올림 → 멈춤(요격 가능) → 휩쓸기)을 검으로. **판정은 검날 + 손**, 팔은 아님 | 팔 휘두르기 대체 |
| **방패 내려찍기** (새) | 왼손 방패 | 요격·회피 | 방패를 들어 플레이어 위치로 내려찍는다 (요새 프레스처럼 그림자 예고). 차지 강습으로 받아치면 튕겨 올라간다 | 새 근접 |
| **방패 동심원** (패리 불가) | 방패 수정 | 회피 돌진 | 방패를 앞으로 세우고 수정에 보라 빛이 차오른 뒤(약 1.2초), 수정에서 보라 동심원이 2~3겹 퍼진다. 회피 돌진의 무적으로 넘는다 | 눈 레이저 대체 |

- 동심원은 요새의 "반응로 동심원 파동"과 같은 규칙·색으로 만든다 → **1스테이지에서 배우고 2스테이지에서 더 세게 다시 만난다.** (요새 쪽 동심원은 그대로 두고 생김새만 맞춘다)
- 낮은 곳을 벌주던 용암 분출이 사라지므로 `LOW_ZONE_Y` 구역 가중치도 없앤다. 헤일로 사격이 플레이어가 어디 있든 위에서 내려온다.

### 4.1 첫 만남 순서 (스크립트로 고정, 이후는 무작위)
1. 조준 연사 → 패리·리버스 드라이브 (첫 탄은 기존 튜토리얼 그대로)
2. 헤일로 사격 → 같은 동작 복습
3. **검 휘두르기** → 이 때 요격 튜토리얼 한 장 (요새 기획 7장에서 정한 위치)
4. 방패 동심원 → 회피 돌진

## 5. 구조: 부위 = 고른 만큼 전장이 바뀐다

| 부위 | 표적 | 부수면 | 차례는 누가 잇나 (DESIGN: 차례는 쉬지 않는다) |
|---|---|---|---|
| 어깨포 ×2 | 포대 윤곽 | 그쪽 포가 터져 떨어진다 | 남은 포 → 둘 다 없으면 **헤일로 렌즈**가 사격 차례를 맡는다 |
| 검 (손목) | 손목 관절 | 검이 부러져 떨어지고 손잡이만 남는다 | 근접 차례를 **방패 내려찍기**가 맡는다 |
| 방패 (가운데 수정) | 수정 둘레 | 방패가 반으로 깨진다 | 동심원은 **헤일로 가운데**에서 작게 (패리 불가를 배울 기회는 남긴다), 내려찍기는 검이 맡는다 |

- 지금은 네 부위를 다 부수면 가슴이 열린다. **9장 관측 봉인 채택: 부위는 가슴을 여는 조건에서 빠진다.**
- 부순 공격이 정말 사라지는 걸 보여 주는 게 부목표의 보상: 검부터 부수면 근접이, 포부터 부수면 탄이 확 줄어든다.

### 5.1 코어 페이즈
- 흐름은 9장 관측 봉인을 따른다: 봉인 셋 → 문 열림(껍질 깎기) → 껍질이 깨지면 문이 닫힘 → 봉인 셋 다시 → 문 열림(맨 코어, 직접 한 대).
- 두 번째 바퀴에는 남은 무기(부서진 부위 제외)와 헤일로가 더 빠르게 쏜다.
- 맨 코어는 직접 때려야 터진다 (v0.78 공통 규칙).

## 6. 표적·게이지

- 표적 테두리는 붉은색, 부위 모양을 따라간다: 어깨포 = 포대 다각형, 검 = 손목 관절 원, 방패 = 수정 둘레 다각형.
- 체력 게이지: 청록 보호 몫을 뺀다 (요새 v0.75와 같이). 페이즈 1에는 부위 균열·연기로, 코어 페이즈에는 코어를 바짝 두른 붉은 링으로만.

## 7. 하지 않는 것

- **방패가 탄·돌진을 막는 기능은 넣지 않는다.** 방어형 기믹("잘린 것을 던져 방패를 깬다")은 미래의 방어형 보스 몫으로 남겨 둔다. 관측자의 방패는 무기(내려찍기·동심원)일 뿐이다.
- 튜토리얼 페이지는 늘리지 않는다 (요격 한 장은 요새에서 옮겨 오는 것).
- 처치 보상·스토리는 그대로.

## 8. 결정 (2026-10-19 사용자)

1. 방패 내려찍기: **넣는다**
2. 방패를 부위(표적)로: **부위로**
3. 검 판정은 날 + 손만: **그렇게** (판정 = 진홍으로 빛나는 곳)
4. 보스 크기: **지금으로 충분** (키우지 않는다)
5. 검날은 금색 아님 (위 3.1)

## 9. 고유 기믹 (채택): 관측 봉인 — 세 가지 동작을 "보여 주면" 가슴이 열린다

지금은 부위 넷을 다 부수면 가슴이 열리는 일직선 소모전이다 (회고 4장). 다른 보스는 저마다 기믹이 있다 — 요새는 포탄을 받아쳐 되꽂기, 크라켄은 촉수 요격으로 방어막 깎기, 결계 위성은 동조로 결계 열기. 관측자는 **이름 그대로 플레이어를 관측하는 보스**로 만든다.

### 9.1 규칙
- 닫힌 가슴 문에 **봉인 셋**이 새겨져 있다. 봉인마다 색이 곧 동작이다:
  - **금 봉인 — 반격**: 금빛 탄을 패리해 리버스 드라이브로 보스(어느 부위든)를 맞힌다
  - **진홍 봉인 — 요격**: 검 휘두르기나 방패 내려찍기를 차지 강습으로 받아친다
  - **보라 봉인 — 회피**: 방패 동심원을 회피 돌진으로 뚫고 지나간다
- 해내는 순간, 헤일로 렌즈 하나가 플레이어 쪽으로 돌며 빛줄기를 쏘아 "관측"하고, 그 빛이 가슴의 해당 봉인으로 흘러가 봉인이 켜지고 금이 간다 (소리 + 짧은 멈춤). 글자나 UI 없이 그림으로만.
- 봉인은 순서 상관없이 **각각 한 번씩** 성공하면 된다. 셋 다 켜지면 가슴 문이 열린다. (2026-10-19 사용자 결정)
- **문이 열린 동안**: 코어 껍질(장갑)에 피해가 들어간다. 문은 **껍질이 다 깨질 때까지 열려 있다.**
- **껍질이 깨지면 문이 다시 닫히고 봉인 셋이 다시 꺼진다.** 다시 세 동작을 한 번씩 보여 주면 문이 열리고, 이번엔 맨 코어 — **직접 한 대**면 터진다.
- 즉 `봉인 3 → 열림(껍질 깎기) → 닫힘 → 봉인 3 → 열림(마지막 한 방)`. 데미지로 문을 열 수는 없다 — 문은 동작으로만 열린다.
- **부위(어깨포·검·방패)는 문을 여는 조건이 아니다.** 부수면 그 공격이 사라질 뿐 (5장) — "전장을 내가 바꾼다"는 부목표로 남는다. 어려우면 부위를 먼저 부숴 편하게 만들고, 자신 있으면 바로 봉인을 노린다.
- 막힘 방지: 어떤 봉인의 공격이 부위 파괴로 모두 사라지면(예: 검과 방패를 둘 다 부숨) 그 봉인은 인정된 것으로 친다 (두 번째 바퀴에도).

### 9.2 왜 이 기믹인가
- **교육용 기조 그대로**: 튜토리얼 페이지를 늘리지 않고, 기본 동작 셋을 각각 한 번 이상 실제로 해 봐야 이긴다. 무엇을 아직 안 했는지 가슴의 꺼진 봉인이 보여 준다.
- **색 규칙을 몸으로 가르친다**: 봉인 색 = 공격 색 = 대응 동작. 이후 보스들은 이 색을 설명 없이 쓴다.
- **구조가 다른 보스와 겹치지 않는다**: "행동하면 딜타임이 열린다"가 아니라 "행동을 보여 주면 관문이 열린다" (원칙 2.6).
- **이름·설정과 맞는다**: 관측자 = 시험관. 봉인이 다 깨지면 "합격"한 플레이어에게 심장을 연다.

### 9.3 대안 (더 단순)
- **부위마다 맞는 동작이 다르다**: 어깨포는 리버스 드라이브로만, 검(손목)은 요격으로만, 방패(수정)는 동심원을 회피 돌진으로 넘은 직후에만 깨진다. 부위 넷 → 가슴 구조는 그대로 두고 부위에 동작을 하나씩 묶는다. 구현은 쉽지만, 표적을 노려도 안 들어가는 이유를 그림으로 설명해야 하는 부담이 있다.
- **9.1 관측 봉인으로 결정** (2026-10-19).

2. 검 휘두르기 (팔 휘두르기를 검 판정으로) · 방패 동심원 (눈 레이저 대체)
3. 헤일로 사격 (용암 분출 삭제)
4. 방패 내려찍기 · 부위 차례 넘기기
5. 관측 봉인 (9장) · 첫 만남 순서 · 요격 튜토리얼 위치 · 게이지 정리
6. 소리 (검 날 소리, 방패 충전음)
