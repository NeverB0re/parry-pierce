# 관측자 리워크 기획서 (1스테이지, 기본 조작 학습)

> 상태: **기획** (v0.78 기준). 외형의 큰 틀(헤일로를 진 망토 입은 거인)은 유지하고 디테일을 살린다. 팔 휘두르기는 **검과 방패**로, 바닥 용암 분출은 **헤일로 렌즈 사격**으로, 눈 레이저는 **방패 동심원**으로 바꾼다.
> 관련: 설계 원칙 [DESIGN_boss_principles.md](DESIGN_boss_principles.md) · 탄막 요새 [BOSS_fortress.md](BOSS_fortress.md) · 크기·구도 기준은 크라켄(v0.67).
> 현재 모습: [img/observer_v078_current.png](img/observer_v078_current.png)

## 1. 지금 무엇이 문제인가

| 문제 | 원인 |
|---|---|
| 바닥 용암 분출이 비직관적이다 | 보스 몸에서 나오지 않는다. 발을 구르면 바닥이 터진다는 인과가 화면에 안 보이고, 시선을 아래로 끌어 흐름이 끊긴다 (요새 기뢰와 같은 문제) |
| 근접이 "팔"이라 읽기 어렵다 | 맨팔을 휘두르는데 팔 어디가 위험한지, 왜 금빛(패리 가능)인지 그림으로 알 수 없다 |
| 패리 불가 공격이 눈 레이저다 | 머리 위 눈에서 가는 선이 나온다 — 작고 멀어서 예고가 약하고, 다른 보스의 패리 불가 공격(요새·크라켄)과 생김새 연결이 없다 |
| 어깨포 표적 원이 그림과 안 맞는다 | 표적 판정이 포신 중간의 원(반지름 55)이라 포대 모양과 겹치지 않는다 |
| 부위를 어떤 순서로 부숴도 결과가 같다 | (회고 4장) 부순 부위의 공격이 사라지는 게 체감되지 않는다 |

## 2. 한 줄 요약

**헤일로를 진 기사형 거인. 검(금빛 날)은 패리·요격하고, 방패가 모아 쏘는 동심원(보라)은 회피 돌진으로 넘고, 어깨포와 헤일로의 탄은 받아쳐 되꽂는다 — 게임의 동사를 하나씩 정직하게 보여 주는 첫 보스.**

- 학습 역할: **기본 조작** — 돌진·차지·패리→리버스 드라이브·요격·회피 돌진을 한 번씩 (깊이는 다음 보스들이 맡는다)
- 부목표의 보상 형태: **전장을 내가 바꾼다** — 고른 부위를 부수면 그 공격이 눈에 띄게 사라진다 (DESIGN 5장)
- 색 규칙을 처음 가르치는 보스: **금색 = 패리 가능**(탄, 검날) · **보라 = 패리 불가**(방패 동심원) · **붉은 원 = 때릴 곳**

## 3. 외형: 헤일로의 기사 (그림 유지 + 디테일)

### 3.1 바뀌는 것
```
          ◯ ◯ ◯  헤일로 렌즈 16개 (금빛) ── 사격 발사점
       ◯    ┌─┐    ◯
     ◯  ▣═══│◉│═══▣  ◯      ▣ 어깨포 (표적: 포대 윤곽 그대로)
        ║ ┌─┴─┴─┐ ║
   검 ━━╋━┥ 가슴 ┝━╋━━ 방패
   (오른손)│ 문  │  (왼손)   ◆ 방패 가운데 수정 = 동심원 발사점
        ╚═╧═════╧═╝
          망토 · 다리
```
- **오른손: 검** — 몸 높이만 한 곧은 장검. 평소엔 어둡고, **휘두를 때만 날이 금빛으로 달아오른다** (= 패리할 수 있다). 칼자루 쪽에 붉은 표적(손목 관절).
- **왼손: 방패** — 몸통 절반을 가리는 탑 방패(직선, 모서리 깎음). 가운데에 눈 문양의 수정. **동심원을 모을 때 수정과 방패 테두리가 보라로 차오른다.**
- **어깨포** — 포대 몸체 + 포신을 직선 판으로 다시 그린다. 표적 테두리는 포대 윤곽(다각형)을 따라간다 (지금의 원 대신).
- **헤일로** — 렌즈 16개는 지금처럼 천천히 돌며 플레이어 쪽이 밝다. 쏠 렌즈만 금빛으로 커지며 달아오른다.

### 3.2 살아 있게 (정물화 금지)
- 숨쉬기: 가슴판·어깨가 아주 천천히 오르내린다. 망토 자락이 흔들린다 (지금도 일부 있음).
- 머리와 두 눈이 플레이어를 따라 돈다. 검 끝이 쉴 때도 살짝 플레이어 쪽으로 기운다.
- 방패를 쥔 팔은 쉴 때 몸 앞을 가렸다 내렸다 한다 (막는 기능은 없다 — 아래 7장).
- 부순 부위는 그대로 남는다: 검이 부러지면 손잡이만 남고, 방패가 깨지면 반쪽 방패, 어깨포는 그을린 포좌.

## 4. 패턴

동시에 1~2개, 탄막과 근접은 겹치지 않는다. 1스테이지라 예고가 길고 탄이 느리다.

| 패턴 | 출처 | 동사 | 내용 | 기존 |
|---|---|---|---|---|
| **조준 연사** (시그니처) | 어깨포 | 패리 → 리버스 드라이브 | 포구가 달아오르며 조준선이 따라오고 5갈래 부채꼴 (가운데 3 주탄) | 유지 |
| **흩뿌리기** | 어깨포 | 회피·잔탄 흡수 | 사방으로 고른 틈 | 유지 |
| **헤일로 사격** (새) | 헤일로 렌즈 | 패리·회피 | 렌즈 3~4개가 차례로 달아올라 각각 느린 주탄 한 발을 플레이어에게. 렌즈는 부서지지 않는다 (배경 발사점) | 용암 분출 대체 |
| **검 휘두르기** | 오른손 검 | 요격·패리 | 지금의 팔 휘두르기 흐름(들어올림 → 멈춤(요격 가능) → 휩쓸기)을 검으로. **판정은 검날 + 손**, 팔은 아님 | 팔 휘두르기 대체 |
| **방패 내려찍기** (새) | 왼손 방패 | 요격·회피 | 방패를 들어 플레이어 위치로 내려찍는다 (요새 프레스처럼 그림자 예고). 차지 강습으로 받아치면 튕겨 올라간다 | 새 근접 |
| **방패 동심원** (패리 불가) | 방패 수정 | 회피 돌진 | 방패를 앞으로 세우고 수정에 보라 빛이 차오른 뒤(약 1.2초), 수정에서 보라 동심원이 2~3겹 퍼진다. 회피 돌진의 무적으로 넘는다 | 눈 레이저 대체 |

- 동심원은 요새의 "반응로 동심원 파동"과 같은 규칙·색으로 만든다 → **1스테이지에서 배우고 2스테이지에서 더 세게 다시 만난다.** (요새 쪽 동심원은 그대로 두고 생김새만 맞춘다)
- 낮은 곳을 벌주던 용암 분출이 사라지므로 `LOW_ZONE_Y` 구역 가중치도 없앤다. 헤일로 사격이 플레이어가 어디 있든 위에서 내려온다.

### 4.1 첫 만남 순서 (스크립트로 고정, 이후는 무작위)
1. 조준 연사 → 패리·리버스 드라이브 (첫 탄은 기존 튜토리얼 그대로)
2. 헤일로 사격 → 같은 동작 복습
3. **검 휘두르기** → 이 때 요격 튜토리얼 한 장 (요새 기획 7장에서 정한 위치)
4. 방패 동심원 → 회피 돌진

## 5. 구조: 부위 = 고른 만큼 전장이 바뀐다

| 부위 | 표적 | 부수면 | 차례는 누가 잇나 (DESIGN: 차례는 쉬지 않는다) |
|---|---|---|---|
| 어깨포 ×2 | 포대 윤곽 | 그쪽 포가 터져 떨어진다 | 남은 포 → 둘 다 없으면 **헤일로 렌즈**가 사격 차례를 맡는다 |
| 검 (손목) | 손목 관절 | 검이 부러져 떨어지고 손잡이만 남는다 | 근접 차례를 **방패 내려찍기**가 맡는다 |
| 방패 (가운데 수정) | 수정 둘레 | 방패가 반으로 깨진다 | 동심원은 **헤일로 가운데**에서 작게 (패리 불가를 배울 기회는 남긴다), 내려찍기는 검이 맡는다 |

- 네 부위를 다 부수면 가슴이 열린다 (지금과 같다).
- 부순 공격이 정말 사라지는 걸 보여 주는 게 부목표의 보상: 검부터 부수면 근접이, 포부터 부수면 탄이 확 줄어든다.

### 5.1 코어 페이즈
- 가슴이 열리고 심장 코어. 남은 무기(부서진 부위 제외)와 헤일로가 더 빠르게 쏜다.
- 맨 코어는 직접 때려야 터진다 (v0.78 공통 규칙).

## 6. 표적·게이지

- 표적 테두리는 붉은색, 부위 모양을 따라간다: 어깨포 = 포대 다각형, 검 = 손목 관절 원, 방패 = 수정 둘레 다각형.
- 체력 게이지: 청록 보호 몫을 뺀다 (요새 v0.75와 같이). 페이즈 1에는 부위 균열·연기로, 코어 페이즈에는 코어를 바짝 두른 붉은 링으로만.

---

## 7. 하지 않는 것

- **방패가 탄·돌진을 막는 기능은 넣지 않는다.** 방어형 기믹("잘린 것을 던져 방패를 깬다")은 미래의 방어형 보스 몫으로 남겨 둔다. 관측자의 방패는 무기(내려찍기·동심원)일 뿐이다.
- 튜토리얼 페이지는 늘리지 않는다 (요격 한 장은 요새에서 옮겨 오는 것).
- 처치 보상·스토리는 그대로.

## 8. 제안 (결정 필요)

1. **방패 내려찍기를 넣을지**: 넣으면 근접이 둘(검·방패)이 되어 검을 부순 뒤에도 요격 연습이 남는다. 빼면 방패는 동심원 전용으로 단순해진다. → **추천: 넣는다** (부위 차례 넘기기 규칙과도 맞는다)
2. **방패를 부위(표적)로 할지**: 부위가 아니면 동심원을 끝까지 피해야 하고 부위는 셋이 된다. → **추천: 부위로** (지금처럼 넷, 고르는 재미)
3. **검 판정을 날+손으로 좁히기**: 지금 팔 휘두르기는 팔 전체가 판정이라 억울한 피격이 있다. 날만 금빛으로 빛나니 판정도 거기만 → **추천**
4. 보스 크기: 크라켄 기준으로 조금 더 키워 헤일로가 화면 위를 꽉 채우게 (원칙: 화면을 채운다)

## 9. 구현 순서 (제안)

1. 외형: 검·방패·어깨포 다시 그리기, 표적 윤곽 (그림만) → 캡처 확인
2. 검 휘두르기 (팔 휘두르기를 검 판정으로) · 방패 동심원 (눈 레이저 대체)
3. 헤일로 사격 (용암 분출 삭제)
4. 방패 내려찍기 · 부위 차례 넘기기
5. 첫 만남 순서 · 요격 튜토리얼 위치 · 게이지 정리
6. 소리 (검 날 소리, 방패 충전음)
