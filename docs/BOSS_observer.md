# 관측자 리워크 기획서 (1스테이지, 기본 조작 학습)

> 상태: **구현 중** (2026-10-19 사용자 결정으로 개정). 외형의 큰 틀(헤일로를 진 망토 입은 거인)은 유지한다.

## 1. 지금 무엇이 문제인가

| 문제 | 원인 |
|---|---|
| 바닥 용암 분출이 비직관적이다 | 보스 몸에서 나오지 않는다. 시선을 아래로 끌어 흐름이 끊긴다 |
| 근접이 "팔"이라 읽기 어렵다 | 맨팔을 휘두른다. 경기장이 좁아 손에 쥔 무기를 휘두르기도 어렵다 |
| 패리 불가 공격이 눈 레이저다 | 작고 멀어서 예고가 약하다 |
| 어깨포 표적 원이 그림과 안 맞는다 | 포신 중간의 원 판정 |
| 부위를 다 부숴야 코어가 열리는 소모전 | 기본 동작을 배우는 보스인데 "무엇을 하면 이기는지"가 동작과 연결되지 않는다 |

## 2. 한 줄 요약

**헤일로를 진 기사형 거인. 가슴의 코어는 처음부터 드러나 있고, 세 가지 기본 동작이 각각 다른 방식으로 코어를 친다.**

| 동작 | 상대 | 결과 |
|---|---|---|
| **패리 → 리버스 드라이브** | 금빛 탄 (어깨포·헤일로) | 되꽂아 코어에 피해 |
| **요격 (차지 강습)** | 떠다니는 대검 | 쳐낸 검이 튕겨 날아가 **코어에 꽂혀** 피해 |
| **완전 동조 (회피 돌진으로 스침)** | 방패 동심원 (보라, 패리 불가) | 동조 버프 → 강한 일격 |

- 학습 역할: **기본 조작**. 튜토리얼 문구는 늘리지 않는다 — 이 세 줄이 그대로 튜토리얼이 된다.
- 색 규칙: **금색 = 패리해서 되꽂을 수 있는 탄** · **진홍 = 근접(요격)** · **보라 = 패리 불가** · **붉은 원 = 때릴 곳**

## 3. 외형

```
          ◯ ◯ ◯  헤일로 렌즈 (금빛) ── 사격 발사점 (부서지지 않음)
       ◯    ┌─┐    ◯
     ◯  ▣═══│◉│═══▣  ◯      ▣ 어깨포 = 유일한 부위 (표적: 포대 윤곽)
        ║ ┌─┴─┴─┐ ║
  방패 ─╢ │ ▦▦▦ │ ╟    ⚔ 떠다니는 대검 (오른쪽 허공)
        ║ │ ▦◆▦ │ ║       ▦ 코어 금고: 3×3 장갑판 아래 호박빛 결정 — 처음부터 드러나 있다
        ╚═╧═════╧═╝
```
- **대검** — 오른손이 허공을 쥔 자세로 조종한다(손과 검 사이 옅은 빛 줄기). 평소엔 몸 오른쪽에 칼끝을 아래로 떠서 천천히 흔들린다. 몸 높이에 맞먹는 크기, 직선 날.
- **방패** — 왼손에 쥔 탑 방패. 휘두르지 않는다. 가운데 수정에 보라 빛을 모아 동심원을 쏜다.
- **코어** — 가슴 문 없이 금고가 드러나 있다. 3×3 장갑판이 맞을 때마다 한 장씩 떨어져 결정이 드러나고, 다 떨어지면 맨 결정(한 대).
- **어깨포** — 각진 포좌 + 곧은 포신 + 제퇴기. 표적 테두리는 포대 윤곽.
- 살아 있게: 숨쉬기, 머리·눈이 플레이어를 따라감, 대검이 쉴 때도 칼끝을 플레이어 쪽으로 살짝 기울임, 망토 흔들림.

## 4. 패턴

동시에 1~2개, 탄막과 근접은 겹치지 않는다. 1스테이지라 예고가 길고 탄이 느리다.

| 패턴 | 출처 | 동사 | 내용 |
|---|---|---|---|
| **조준 연사** (시그니처) | 어깨포 | 패리 → 리버스 드라이브 | 포구가 달아오르며 조준선, 5갈래 부채꼴 (가운데 3 주탄) — 유지 |
| **흩뿌리기** | 어깨포 | 회피·잔탄 흡수 | 사방으로 고른 틈 — 유지 |
| **헤일로 사격** | 헤일로 렌즈 | 패리·회피 | 렌즈 3~4개가 차례로 달아올라 느린 주탄을 한 발씩. 용암 분출 대체 (다음 단계) |
| **대검 긋기** | 떠다니는 대검 | 요격 | 대검이 플레이어 옆 허공으로 떠올라 자세를 잡고(예고: 진홍 부채꼴 띠) 큰 호를 그으며 벤다. 자세를 잡은 뒤~긋는 중에 차지 강습으로 쳐내면 검이 튕겨 날아가 코어에 꽂힌다 |
| **방패 동심원** (패리 불가) | 방패 수정 | 회피 돌진 · 완전 동조 | 수정에 보라 빛이 차오른 뒤(약 1.2초) 동심원이 퍼진다. 회피 돌진으로 스치면 완전 동조 |

- 동심원은 요새의 동심원과 같은 규칙·색 → 1스테이지에서 배우고 2스테이지에서 더 세게 만난다.
- 어깨포가 둘 다 부서지면 사격 차례는 헤일로 렌즈가 잇는다 (차례는 쉬지 않는다).

## 5. 구조

- **코어는 처음부터 표적이다.** 돌진·차지·리버스 드라이브·쳐낸 대검·반사탄 모두 코어 장갑을 깎는다.
- **어깨포 둘 = 부목표**: 부수면 그쪽 탄이 멎는다 (전장을 내가 바꾼다). 코어를 여는 조건이 아니다.
- 장갑이 다 떨어지면 맨 결정 — **직접 한 대**면 터진다 (반사탄·쳐낸 검은 마지막 한 방이 되지 못한다, v0.78 공통 규칙).
- 페이즈 구분(개방 연출)은 없다.

---

## 6. 표적·게이지

- 표적 테두리는 붉은색, 부위 모양을 따라간다: 어깨포 = 포대 다각형, 코어 = 금고 둘레.
- 체력 게이지: 코어 장갑만, 코어를 두른 붉은 링 (청록 보호 몫 없음).

---

## 7. 하지 않는 것

- 방패가 탄·돌진을 막는 기능 (방어형 기믹은 미래의 방어형 보스 몫).
- 튜토리얼 페이지 추가 (요격 한 장은 첫 대검 긋기 때 — 요새 기획에서 옮겨 오는 것).
- 보스 크기 변경 (지금으로 충분).
