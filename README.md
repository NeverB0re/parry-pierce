# Parry Pierce — Godot 프로토타입

배경에 선 거대한 적의 공격을 **패리**해 날아오르고, 외부 시스템을 부수고, 마지막에 열린 가슴의 **동력 코어**에서 에너지를 확보하는 2D 액션 프로토타입.
아이디어와 변경 기록은 [docs/DESIGN.md](docs/DESIGN.md). 재검토·개발 방향은 [docs/REVIEW_roadmap.md](docs/REVIEW_roadmap.md), 보스 기획은 [docs/PLAN_colossi.md](docs/PLAN_colossi.md). 배경 스토리·세계관은 [docs/STORY.md](docs/STORY.md).

> 최신 빌드: [Releases](https://github.com/NeverB0re/parry-pierce/releases) (v0.33). 무제한 돌진·코어 체력제 기획: [docs/PLAN_dash_rework.md](docs/PLAN_dash_rework.md).

## 실행
- 바로 플레이: [Releases](../../releases)에서 `ParryPierce.exe` 다운로드 (Windows)
- 안드로이드: 릴리즈의 `ParryPierce-android.apk`를 폰에 내려받아 설치 ("출처를 알 수 없는 앱 설치" 허용 필요, 디버그 서명, arm64, 가로 화면)
- 소스: Godot **4.7** 에서 이 폴더(`project.godot`)를 열고 F5

사운드는 전부 합성하고, 보스·배경은 코드로 그립니다. 플레이어 기체·노즐 화염·폭발 이펙트는 도트 스프라이트(Ravenmore "Space Rage", [art/CREDITS.md](art/CREDITS.md))를 씁니다.

## 조작
| 입력 | 동작 |
|---|---|
| 마우스 | 기체 머리 방향. 위로 두면 활공(화염이 길어지고 천천히 떨어짐), 아래로 두면 빨리 떨어짐 |
| 좌클릭 (짧게) | **돌진** — 무적, 잔상. 표적에 닿으면 **피해 1** 후 튕겨남. 자원 없이 **쿨다운 0.9초** (기체 주변 얇은 링이 차오름). 쿨다운이 거의 끝났을 때 누른 입력은 기억했다가 바로 나감 |
| 좌클릭 꾹 (0.6초) | **차지 강습** — 피해 **3**. 다 모으면 잠시 후 자동 발사. 덜 모으고 떼면 일반 돌진. 차지 강습(요격 포함) 뒤 **1.5초 차지 쿨다운**(기체 주변 주황 링) — 그동안은 모이지 않고(감속도 없음), 누르고 있으면 쿨다운이 끝난 뒤부터 모인다 |
| (차지 강습이 팔에 부딪힘) | **요격** — 팔이 위치를 잡고 공격 직전 멈춰 있을 때(들어올리는 중은 제외)나 휘두르는 중에 부딪히면 그 팔 구동부에 즉시 **8**, 공격이 끊기고 팔이 밀려나 1초 멈춤 |
| (돌진 직후 0.12초) | **퍼펙트 회피** — 그 순간 공격이 스치면 추가 무적 0.8초 + 짧은 슬로우 + **돌진 쿨다운 즉시 초기화** + **동조**: 4초 동안 다음 차지 강습 피해 2배·차지 시간 절반(청백 오라, 마지막 1초는 깜빡임). 다시 얻으면 4초로 갱신, 끝날 무렵 시전한 차지 강습은 끝날 때까지 유지, 슬로우 중엔 느리게 줄어듦. 맞으면 소멸. 그냥 무적으로 통과한 것은 보상 없음 |
| (패리 불가 레이저를 퍼펙트 회피) | **강한 퍼펙트 회피** — 위와 같되 **다음 차지 강습 피해 4배**(완전 동조), 무적 1.2초, 더 긴 슬로우, 금빛·청록 이중 오라. 그 일격은 퍼펙트 패리 급 임팩트. 요격에는 4배가 아니라 2배만 적용 |
| 우클릭 / Space 꾹 | **패리**. 탄을 패리하면 시간이 느려지고 → 방향을 정해 버튼을 떼면(또는 좌클릭) **리버스 드라이브** (피해 **12**, PERFECT **16**). 휩쓰는 팔을 그냥 패리하면 피해는 막지만 리버스 드라이브 없이 반대로 튕겨나기만 함 |
| R | 재시작 |
| Esc | 메뉴 (플레이 중엔 마우스가 창 밖으로 나가지 않음) |

돌진이 표적에 적중하면 **위로 솟구칩니다**(v0.6 방식): 들어온 반대쪽으로 약간 밀리고, 마우스 좌우로 조종할 수 있습니다. 차지 강습·리버스 드라이브일수록 조금 더 높이 솟구칩니다(높이는 v0.6보다 약 25% 낮춤). 적중 후 0.9초 무적이고 패리는 바로 쓸 수 있지만 돌진 쿨다운은 그대로 흐릅니다. 맞아서 추락(제어 불능)하는 동안 좌클릭을 눌러 두면 제어 불능이 끝나자마자 모으기가 시작됩니다. 패리 후 조준 유예는 1.4초(PERFECT 1.9초).

**표적(외부 시스템·코어)은 돌진 중에만 충돌합니다.** 그 밖에는 통과하며 접촉 피해도 없습니다. 피해는 적의 공격(근접 팔 휩쓸기·탄·레이저)으로만 받습니다.

## 튜토리얼
새 메커니즘이 처음 나오면 게임이 멈추고 팝업이 뜹니다 (짧은 반복 애니메이션 + 설명, Enter/클릭으로 닫기).
시작할 때 **회피 → 패리** 두 장, 적이 처음 팔을 들 때 **차지 강습·요격**, 처음 눈 레이저를 준비할 때 **패리 불가**.
한 번 본 장은 다시 자동으로 뜨지 않고(`user://tutorial.cfg`), **ESC 메뉴 → 조작법**에서 장별로 다시 볼 수 있습니다.
시작·부활 직후에는 플레이어가 불시착 지점에서 날아오르기 전까지 적이 공격을 시작하지 않습니다.

## 에임 어시스트
차지가 완료됐거나 패리 후 조준 중일 때, 사거리 안의 표적(외부 시스템·장갑·동력 코어) 가장자리에서 PC 약 24도 / 터치 약 40도 이내로 조준선이 들어오면 표적 중심으로 달라붙고(고리 표시), 멀어질수록 부드럽게 풀립니다.

## 흐름
1. 바닥은 전부 **융해 지대**(녹아내린 행성 표면). 그 위의 작은 불시착 지점에서 시작 — 첫 돌진은 **발사**가 되어 거인의 어깨 높이까지 솟구치고, 불시착 지점은 가라앉는다.
2. 거인은 배경이라 몸은 통과한다. **공격과 표적만** 판정이 있다.
3. 적의 공격(팔 휩쓸기·탄·레이저)에 맞으면 **실드 셀(기체 아이콘) 1개**를 잃고 **제어 불능**: 0.9초 조작 불가 + 살짝 솟구친 뒤 추락.
4. 융해 지대에 빠지면 실드 셀 1개를 잃고 불시착 지점에서 재출격 (부순 외부 시스템은 유지). 실드 셀 3개를 다 잃으면 처음부터. 잃은 실드 셀은 식은 회색 기체 아이콘으로 표시됩니다.
5. **페이즈 1 — 외부 시스템 파괴**: 좌/우 어깨 포대, 좌/우 팔꿈치 구동부 (각 체력 24). 체력바 대신 긁힘 → 빛나는 균열·불꽃 → 장갑 조각 탈락·연기로 손상이 보인다. 부수면 떨어져 나가고 그 공격도 사라진다.
6. **페이즈 2 — 코어**: 넷 다 부수면 가슴이 열리고 불규칙한 강철 판(장갑)에 싸인 **동력 코어**가 드러난다. 판은 피해에 따라 하나씩 찌그러지고 → 휘고 금이 가며 덜컹거리고 → 뜯겨 떨어져 나가며 안의 코어가 드러난다 (장갑 체력 160). 장갑이 다 부서져도 **코어에 한 발을 더** 맞혀야 에너지를 확보한다 — 남는 피해는 코어로 넘어가지 않고, 장갑이 부서진 직후 0.35초는 코어가 부서지지 않는다.

## 진행 (스테이지 · 정비 · FTL 도약)
- 스테이지 하나 = 콜로서스 하나. 코어 에너지를 확보하면 배너에서 **클릭(또는 Enter)** → **정비 화면** → **FTL 도약** → 다음 스테이지. 지금은 관측자 하나뿐이라 같은 스테이지로 다시 도약한다.
- 실드 셀을 다 잃으면 **그 스테이지부터** 다시. 진행은 클리어할 때 `user://profile.cfg` 에 저장된다.
- 콜로서스를 **처음** 처리하면 그 **코어 아이템**(관측자 = 기동 코어: 돌진 거리 +25%, 활공 낙하 감소)과 **부산물 포인트 1**. 재도전으로는 얻지 않는다.
- 정비 화면: 포인트로 노드 트리 3개(판정 완화 A1~A5 · 스텟 증가 P1~P5 · 유틸리티 U1~U5, [docs/PLAN_upgrade.md](docs/PLAN_upgrade.md))를 찍는다. 노드는 **단계**가 있어서 콜로서스 1기를 처리하면 1단계(각 트리의 첫 두 노드), 2기면 2단계, 3기면 정점이 열린다. 선행 노드도 필요하고, 되돌릴 수 없어서 **두 번 눌러야 확정**된다. 코어는 하나만 장착하고 언제든 바꿀 수 있다.
- 스테이지: ① 관측자 (기동 코어) → ② 탄막 요새 (반사 코어). 마지막 스테이지를 깨면 같은 스테이지로 다시 도약한다.
- ESC 메뉴 → "정비"로도 들어갈 수 있다 (도약하면 지금 스테이지를 처음부터).

## 적의 공격 (패리할 수 있는 것은 금색, 패리 불가는 검붉은 보라)
- **용융물 분출**: 거인이 발을 구르면 융해 지대 표면이 부글거리다가 아래에서 용융물 덩어리가 플레이어 높이까지 솟구친다
- **팔 휩쓸기**: 준비 모션(팔이 뒤로 젖혀짐, 이때까지만 플레이어를 조준) → 팔 고정 → 실제 공격 범위가 붉게 점멸 → 곧게 편 팔 전체로 휩쓴다. 고정된 뒤에는 경로가 바뀌지 않는다. 차지 강습으로 받아치면 구동부에 피해가 들어가고 팔이 밀려나 1초간 멈춘다. 그냥 패리하면 튕겨나기만 한다
- **눈 레이저 (패리 불가)**: 눈이 보랏빛으로 달아오른 뒤, 광선이 맵을 왼쪽에서 아래를 지나 오른쪽까지 긋는다. 지나갈 부채꼴과 벽·바닥의 도착 경로가 표시되고, 머리가 화면 밖이면 화면 가장자리에 방향 화살표가 뜬다. 돌진(무적)으로 통과해야 한다
- **탄 부채꼴 / 흩뿌리기**: 페이즈 1은 플레이어에게서 먼 쪽 어깨 포대, 최종 페이즈는 머리에서. 외부 시스템을 부술수록 빨라진다

## 콜로서스 ② 탄막 요새 (패리 중심형)
- 무한궤도 위의 포대 요새. 외부 시스템: 좌/우 **주포대**(위), 좌/우 **유도탄 사일로**(아래). 다 부수면 방폭문이 위아래로 열리고 팔각 장갑의 **반응로**(장갑 180)가 드러난다.
- **주탄과 잔탄**: 큰 금색 탄(주탄)과 고리가 도는 **유도탄**을 패리하면 리버스 드라이브. 작은 금색 탄(**잔탄**)은 패리하면 **흡수**되어 사라지기만 한다 (조준 없음, 패리 판정이 열려 있는 동안 연달아 흡수).
- 공격: **나선 탄막**(회전 방향 예고 후 잔탄을 양쪽으로 돌려 뿌리고 그 사이 주탄을 조준 사격) · **부채 탄막**(넓은 잔탄 부채 3연발, 가운데 한 발이 주탄) · **유도탄**(크고 느리게 쫓아옴) · **융해 기뢰**(바닥에 내려앉아 깜빡이다 위로 잔탄 부채 — 낮은 곳일수록 자주).
- 처치하면 **반사 코어**: 리버스 드라이브 중(과 끝난 직후 0.3초) 기체 둘레 70px 안에 닿은 탄을 지금 표적으로 되돌린다. 탄 하나당 피해 1, 유도탄은 3. 반사된 탄은 청백색.

## 개발용
- **테스트**: `GODOT=<Godot 콘솔 실행 파일> tests/run.sh` — 규칙 테스트 + 그리기 스모크를 헤드리스로 전부 실행 (창이 뜨지 않음). 화면 캡처 스크립트는 `tests/capture/`.
- **동작 궤적**: `run.sh` 마지막에 시드·입력을 고정한 4200 프레임 궤적을 `tests/golden/trace.txt` 와 비교한다. 리팩터는 "같음"이어야 하고, 수치·규칙을 일부러 바꿨다면 `tests/run.sh --update-trace` 로 기준을 갱신한다.
- **디버그 키**: F1 오버레이(상태·수치·프레임) · F2 무적 · F3 적 공격 정지 · F4 코어 페이즈로 건너뛰기 · F5 게임 속도 0.5배 · F6 튜토리얼 기록 초기화 · F7 부산물 포인트 +1 · F8 진행 초기화(저장 삭제)
- **플레이 기록**: 한 판마다 `user://telemetry/run_*.json` (Windows: `%APPDATA%/Godot/app_userdata/Parry Pierce (prototype)/telemetry`). ESC 메뉴 → "플레이 기록 폴더 열기". 패리·퍼펙트 회피 횟수, 공격별 피해, 피격 원인, 페이즈 시각이 남는다. 이 파일을 보내 주면 수치 조정에 쓴다.
