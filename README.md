# Parry Pierce — Godot 프로토타입

배경에 선 거대한 적의 공격을 **패리**해 날아오르고, 부위를 부수고, 마지막에 열린 가슴의 **심장**을 꿰뚫는 2D 액션 프로토타입.
아이디어와 변경 기록은 [docs/DESIGN.md](docs/DESIGN.md).

## 실행
- 바로 플레이: [Releases](../../releases)에서 `ParryPierce.exe` 다운로드 (Windows)
- 소스: Godot **4.7** 에서 이 폴더(`project.godot`)를 열고 F5

그래픽/사운드 에셋 없이 전부 코드로 그리고 합성합니다.

## 조작
| 입력 | 동작 |
|---|---|
| 마우스 | 이동하고 싶은 방향 (위로 두면 활공 — 스스로 상승은 불가) |
| 좌클릭 | 돌진 = 공격 (게이지 1칸, 타격 성공 시 환급) |
| 좌클릭 꾹 | 차지 (0.8초마다 게이지 1칸 더, 최대 3단계. 최대 차지는 잠시 후 자동 발사) |
| 우클릭 / Space 꾹 | 패리. 성공하면 게이지 가득 + 시간이 느려지고, 마우스로 방향을 정해 버튼을 떼면(또는 좌클릭) 강한 패리 돌진 |
| R | 재시작 |
| Esc | 메뉴 (플레이 중엔 마우스가 창 밖으로 나가지 않음) |

## 흐름
1. 바닥에서 시작 — 화면엔 거인의 발만 보인다. 거인은 배경이라 몸은 통과하고, **공격과 표적만** 판정이 있다.
2. **페이즈 1 — 부위 파괴**: 좌/우 어깨 포대, 좌/우 팔꿈치 관절이 표적. 돌진으로 부수면 떨어져 나가고 그 공격도 사라진다.
3. 표적은 상시 판정: 돌진 중에 닿으면 타격, 그냥 닿으면 피해.
4. **페이즈 2 — 코어**: 넷 다 부수면 가슴이 열리고 하트 모양 갑옷에 싸인 심장이 드러난다. 탄은 머리에서, 점점 빨라진다.
5. 갑옷에 구멍을 뚫고 돌진으로 심장을 꿰뚫으면 승리.
6. 바닥에 떨어지면 진행은 그대로, 다시 올라가야 한다. HP 3개를 잃으면 전체 리셋.

## 적의 공격
- **내려찍기**: 발이 들리면 착지 때 양쪽으로 충격파 (바닥 근처)
- **팔 휩쓸기**: 부채꼴 경고(시작선이 밝음, 화살표가 휩쓰는 방향) 뒤 팔 전체로 휩쓴다. 패리하거나 돌진으로 빠져나간다
- **탄 부채꼴 / 흩뿌리기**: 페이즈 1은 플레이어에게서 먼 쪽 어깨 포대, 최종 페이즈는 머리에서

## 파일
| 파일 | 내용 |
|---|---|
| `scripts/main.gd` | 루프, 입력, 패리/피격 판정, 카메라, 히트스톱·흔들림·플래시 |
| `scripts/player.gd` | 이동/돌진/차지/패리/직격 반동. **튜닝값은 파일 맨 위 상수** |
| `scripts/boss.gd` | 거인: 부위·페이즈, 갑옷 격자, 심장, 공격 패턴. 튜닝값은 맨 위 상수 |
| `scripts/hud.gd`, `pause_menu.gd` | 체력 가면, 게이지, 표적 방향 화살표 / ESC 메뉴 |
| `scripts/background.gd`, `ground.gd` | 실크송풍 패럴랙스 배경, 바닥/벽/풀 |
| `scripts/fx.gd`, `sfx.gd` | 파티클, 합성 효과음 |
