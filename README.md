# Parry Pierce — Godot 프로토타입

배경에 선 거대한 적의 공격을 **패리**해 날아오르고, 부위를 부수고, 마지막에 열린 가슴의 **심장**을 꿰뚫는 2D 액션 프로토타입.
아이디어와 변경 기록은 [docs/DESIGN.md](docs/DESIGN.md).

## 실행
- 바로 플레이: [Releases](../../releases)에서 `ParryPierce.exe` 다운로드 (Windows)
- 소스: Godot **4.7** 에서 이 폴더(`project.godot`)를 열고 F5

그래픽/사운드 에셋 없이 전부 코드로 그리고 합성합니다.

## 조작
| 입력 | 동작 |
|---|---|
| 마우스 | 로켓 머리 방향. 위로 두면 활공(화염이 길어지고 천천히 떨어짐), 아래로 두면 빨리 떨어짐 |
| 좌클릭 (짧게) | **회피 돌진** — 공격 판정 없음, 무적, 반투명 잔상 (게이지 1칸) |
| 좌클릭 꾹 (0.6초) | **차지 공격 돌진** — 피해 1, 적중 시 게이지 1칸 환급. 다 모으면 잠시 후 자동 발사 (게이지 1칸). 쓴 뒤 1.5초 쿨다운(플레이어 주변 링이 차오름. 쿨다운 중에 누르고 있으면 링이 커지며 '아직 안 됨'을 알리고, 떼면 회피). 회피 도중 누른 클릭은 회피 무적이 끝나는 즉시 차지로 이어짐. 모으는 동안 떨리고, 완료되면 살짝 빛남 |
| (회피 중 공격 통과) | **일반 회피 성공** — 회피 무적으로 공격을 통과하면 게이지 1칸 환급 + 짧은 슬로우 |
| (회피 직후 0.12초) | **퍼펙트 회피** — 그 순간 공격이 스치면 게이지 **2칸** 환급 + 추가 무적 0.8초 + 긴 청록 슬로우 + **다음 차지 공격 피해 3배·차지 시간 절반**(청백 오라) + 아주 짧은 슬로우. 맞으면 버프 소멸. 패리 돌진에는 적용되지 않음 |
| 우클릭 / Space 꾹 | **패리**. 성공하면 게이지 가득 + 시간이 느려지고 노릴 표적이 빛남 → 마우스로 방향을 정해 버튼을 떼면(또는 좌클릭) **패리 돌진** (피해 3). 돌진이 적중할 때까지 월드만 느려지고 플레이어는 실시간 |
| R | 재시작 |
| Esc | 메뉴 (플레이 중엔 마우스가 창 밖으로 나가지 않음) |

게이지는 **3칸**입니다. 패리 성공이 유일한 완전 충전 수단이고, 게이지가 바닥나면 4초 뒤 1칸까지만 천천히 되살아납니다(HUD 첫 칸의 링). 맞아서 추락(스턴)하는 동안 좌클릭을 눌러 두면 스턴이 끝나자마자 차지가 시작됩니다. 돌진이 적중해 튕겨나올 때도 회피·차지·패리를 바로 쓸 수 있습니다. 적중하면 입사각 = 반사각으로 튕겨나며, 아래에서 위로 칠 때만 위로 보정됩니다.

## 흐름
1. 바닥은 전부 **용암**. 용암 위 작은 발판에서 시작 — 첫 돌진은 **발사**가 되어 거인의 어깨 높이까지 솟구치고, 발판은 가라앉는다.
2. 거인은 배경이라 몸은 통과한다. **공격과 표적만** 판정이 있다.
3. 공격에 맞으면 **목숨(가면) 1개**를 잃고 **스턴**: 0.9초 조작 불가 + 살짝 솟구친 뒤 추락. 공격 돌진이 아닐 때 표적에 닿으면 스턴만 (피해 없음).
4. 용암에 빠지면 목숨 1개를 잃고 시작 발판에서 재출격 (부순 부위는 유지). 가면 3개를 다 잃으면 처음부터.
5. **페이즈 1 — 부위 파괴**: 좌/우 어깨 포대, 좌/우 팔꿈치 관절. 부수면 떨어져 나가고 그 공격도 사라진다.
6. **페이즈 2 — 코어**: 넷 다 부수면 가슴이 열리고 하트 모양 갑옷에 싸인 심장이 드러난다. 구멍을 뚫고 심장을 꿰뚫으면 승리.

## 적의 공격 (패리할 수 있는 것은 금색, 패리 불가는 검붉은 보라)
- **용암 분출**: 거인이 발을 구르면 용암 표면이 부글거리다가 아래에서 용암 덩어리가 플레이어 높이까지 솟구친다
- **팔 휩쓸기**: 준비 모션(팔이 뒤로 젖혀짐, 이때까지만 플레이어를 조준) → 팔 고정 → 실제 공격 범위가 붉게 점멸 → 곧게 편 팔 전체로 휩쓴다. 고정된 뒤에는 경로가 바뀌지 않는다. 패리하면 팔이 천천히 밀려나 1초간 멈추고 팔꿈치가 드러난다
- **눈 레이저 (패리 불가)**: 눈이 보랏빛으로 달아오른 뒤, 광선이 맵을 왼쪽에서 아래를 지나 오른쪽까지 긋는다. 지나갈 부채꼴과 벽·바닥의 도착 경로가 표시되고, 머리가 화면 밖이면 화면 가장자리에 방향 화살표가 뜬다. 회피 돌진(무적)으로 통과해야 한다
- **탄 부채꼴 / 흩뿌리기**: 페이즈 1은 플레이어에게서 먼 쪽 어깨 포대, 최종 페이즈는 머리에서. 부위를 부술수록 빨라진다

## 파일
| 파일 | 내용 |
|---|---|
| `scripts/main.gd` | 루프, 입력, 패리/피격 판정, 카메라, 히트스톱·흔들림·플래시 |
| `scripts/player.gd` | 이동/돌진/차지/패리/직격 반동. **튜닝값은 파일 맨 위 상수** |
| `scripts/boss.gd` | 거인: 부위·페이즈, 갑옷 격자, 심장, 공격 패턴. 튜닝값은 맨 위 상수 |
| `scripts/hud.gd`, `pause_menu.gd` | 체력 가면, 게이지, 표적 방향 화살표 / ESC 메뉴 |
| `scripts/background.gd`, `ground.gd` | 실크송풍 패럴랙스 배경, 바닥/벽/풀 |
| `scripts/fx.gd`, `sfx.gd` | 파티클, 합성 효과음 |
