# Parry Pierce — Godot 프로토타입

배경에 선 거대한 적의 공격을 **패리**해 날아오르고, 부위를 부수고, 마지막에 열린 가슴의 **코어**를 부수는 2D 액션 프로토타입.
아이디어와 변경 기록은 [docs/DESIGN.md](docs/DESIGN.md).

> 이 문서는 `dash-rework` 브랜치 기준입니다 (무제한 돌진·코어 체력제). 기획: [docs/PLAN_dash_rework.md](docs/PLAN_dash_rework.md). 빌드는 프리릴리즈 `v0.30-a*`.

## 실행
- 바로 플레이: [Releases](../../releases)에서 `ParryPierce.exe` 다운로드 (Windows)
- 안드로이드: 릴리즈의 `ParryPierce-android.apk`를 폰에 내려받아 설치 ("출처를 알 수 없는 앱 설치" 허용 필요, 디버그 서명, arm64, 가로 화면)
- 소스: Godot **4.7** 에서 이 폴더(`project.godot`)를 열고 F5

사운드는 전부 합성하고, 보스·배경은 코드로 그립니다. 플레이어 기체·노즐 화염·폭발 이펙트는 도트 스프라이트(Ravenmore "Space Rage", [art/CREDITS.md](art/CREDITS.md))를 씁니다.

## 조작
| 입력 | 동작 |
|---|---|
| 마우스 | 로켓 머리 방향. 위로 두면 활공(화염이 길어지고 천천히 떨어짐), 아래로 두면 빨리 떨어짐 |
| 좌클릭 (짧게) | **돌진** — 무적, 잔상. 표적에 닿으면 **피해 1** 후 튕겨남. 자원 없이 **쿨다운 0.7초** (기체 주변 얇은 링이 차오름). 쿨다운이 거의 끝났을 때 누른 입력은 기억했다가 바로 나감 |
| 좌클릭 꾹 (0.6초) | **차지 돌진** — 피해 **3**. 다 모으면 잠시 후 자동 발사. 덜 모으고 떼면 일반 돌진 |
| (차지 돌진이 휩쓰는 팔에 부딪힘) | **받아치기** — 그 팔 관절에 즉시 **8**, 팔이 밀려나 1초 멈춤 |
| (돌진 직후 0.12초) | **퍼펙트 회피** — 그 순간 공격이 스치면 추가 무적 0.8초 + 청록 슬로우 + **돌진 쿨다운 즉시 초기화** + **다음 차지 피해 2배·차지 시간 절반**(청백 오라). 맞으면 버프 소멸. 그냥 무적으로 통과한 것은 보상 없음 |
| 우클릭 / Space 꾹 | **패리**. 탄을 패리하면 시간이 느려지고 → 방향을 정해 버튼을 떼면(또는 좌클릭) **패리 돌진** (피해 **12**, PERFECT **16**). 휩쓰는 팔을 그냥 패리하면 피해는 막지만 패리 돌진 없이 반대로 튕겨나기만 함 |
| R | 재시작 |
| Esc | 메뉴 (플레이 중엔 마우스가 창 밖으로 나가지 않음) |

돌진이 표적에 적중하면 **위로 솟구칩니다**(v0.6 방식): 들어온 반대쪽으로 약간 밀리고, 마우스 좌우로 조종할 수 있습니다. 차지·패리 돌진일수록 조금 더 높이 솟구칩니다(높이는 v0.6보다 약 25% 낮춤). 적중 후 0.9초 무적이고 패리는 바로 쓸 수 있지만 돌진 쿨다운은 그대로 흐릅니다. 맞아서 추락(스턴)하는 동안 좌클릭을 눌러 두면 스턴이 끝나자마자 모으기가 시작됩니다. 패리 후 조준 유예는 1.4초(PERFECT 1.9초).

**표적(부위·코어)은 돌진 중에만 충돌합니다.** 그 밖에는 통과하며 접촉 피해도 없습니다. 피해는 적의 공격(근접 팔 휩쓸기·탄·레이저)으로만 받습니다.

## 에임 어시스트
차지가 완료됐거나 패리 후 조준 중일 때, 사거리 안의 표적(부위·갑옷·심장) 가장자리에서 PC 약 24도 / 터치 약 40도 이내로 조준선이 들어오면 표적 중심으로 달라붙고(고리 표시), 멀어질수록 부드럽게 풀립니다.

## 모바일 조작 (터치)
| 입력 | 동작 |
|---|---|
| 왼쪽 화면 드래그 | 플로팅 스틱 = 방향 (위=활공, 아래=급강하, 놓으면 마지막 방향 유지) |
| 오른쪽 아래 큰 금색 버튼 (꾹) | 패리 → 차지. 모으는 동안 안쪽 호가 차고 쿨다운은 바깥 링. 패리 성공 후 스틱으로 방향을 정하고 손을 떼면 패리 돌진 |
| 그 왼쪽 위에 맞닿은 작은 청백 버튼 | 탭 = 회피 (패리 조준 중 탭 = 즉시 발사) |
| 우상단 ⏸ | 일시정지 메뉴 |

패리·퍼펙트 회피 성공 시 진동이 있습니다. 데스크톱에서 터치 UI를 시험하려면 `-- --touch` 로 실행합니다.

## 흐름
1. 바닥은 전부 **용암**. 용암 위 작은 발판에서 시작 — 첫 돌진은 **발사**가 되어 거인의 어깨 높이까지 솟구치고, 발판은 가라앉는다.
2. 거인은 배경이라 몸은 통과한다. **공격과 표적만** 판정이 있다.
3. 적의 공격(팔 휩쓸기·탄·레이저)에 맞으면 **목숨(기체 아이콘) 1개**를 잃고 **스턴**: 0.9초 조작 불가 + 살짝 솟구친 뒤 추락.
4. 용암에 빠지면 목숨 1개를 잃고 시작 발판에서 재출격 (부순 부위는 유지). 로켓 3개를 다 잃으면 처음부터. 잃은 목숨은 박살난 회색 잔해로 표시됩니다.
5. **페이즈 1 — 부위 파괴**: 좌/우 어깨 포대, 좌/우 팔꿈치 관절 (각 체력 24). 체력바 대신 긁힘 → 빛나는 균열·불꽃 → 장갑 조각 탈락·연기로 손상이 보인다. 부수면 떨어져 나가고 그 공격도 사라진다.
6. **페이즈 2 — 코어**: 넷 다 부수면 가슴이 열리고 하트 모양 강철 껍질에 싸인 코어(체력 160)가 드러난다. 피해 20%마다 껍질이 패이고 → 금이 가 빛이 새고 → 판이 떨어져 나가고 → 뼈대만 남는다. 코어를 부수면 승리.

## 적의 공격 (패리할 수 있는 것은 금색, 패리 불가는 검붉은 보라)
- **용암 분출**: 거인이 발을 구르면 용암 표면이 부글거리다가 아래에서 용암 덩어리가 플레이어 높이까지 솟구친다
- **팔 휩쓸기**: 준비 모션(팔이 뒤로 젖혀짐, 이때까지만 플레이어를 조준) → 팔 고정 → 실제 공격 범위가 붉게 점멸 → 곧게 편 팔 전체로 휩쓴다. 고정된 뒤에는 경로가 바뀌지 않는다. 차지 돌진으로 받아치면 관절에 피해가 들어가고 팔이 밀려나 1초간 멈춘다. 그냥 패리하면 튕겨나기만 한다
- **눈 레이저 (패리 불가)**: 눈이 보랏빛으로 달아오른 뒤, 광선이 맵을 왼쪽에서 아래를 지나 오른쪽까지 긋는다. 지나갈 부채꼴과 벽·바닥의 도착 경로가 표시되고, 머리가 화면 밖이면 화면 가장자리에 방향 화살표가 뜬다. 돌진(무적)으로 통과해야 한다
- **탄 부채꼴 / 흩뿌리기**: 페이즈 1은 플레이어에게서 먼 쪽 어깨 포대, 최종 페이즈는 머리에서. 부위를 부술수록 빨라진다

## 파일
| 파일 | 내용 |
|---|---|
| `scripts/main.gd` | 루프, 입력, 패리/피격 판정, 카메라, 히트스톱·흔들림·플래시 |
| `scripts/player.gd` | 이동/돌진/차지/패리/직격 반동. **튜닝값은 파일 맨 위 상수** |
| `scripts/boss.gd` | 거인: 부위·페이즈, 코어(강철 껍질), 손상 단계 그림, 공격 패턴. 튜닝값은 맨 위 상수 |
| `scripts/hud.gd`, `pause_menu.gd` | 목숨(로켓 아이콘), 표적 방향 화살표 / ESC 메뉴 |
| `scripts/background.gd`, `ground.gd` | 실크송풍 패럴랙스 배경, 바닥/벽/풀 |
| `scripts/fx.gd`, `sfx.gd` | 파티클, 합성 효과음 |

## 빌드
```
godot --headless --path . --export-release "Windows Desktop" ParryPierce.exe
godot --headless --path . --export-debug "Android" ParryPierce.apk
```
안드로이드 내보내기는 Godot 안드로이드 템플릿, Android SDK(platform-tools, build-tools 36.1.0, platform android-36), JDK 17+, 디버그 키스토어가 필요합니다.
